# 대외용 한글 문서 작성

가이드라인, 가이드북, 기술 리포트처럼 밖에서 읽을 한글 문서를 쓰거나 고칠 때 적용합니다. 채팅 답변,
커밋 메시지, 주석, 내부 메모에는 적용하지 않습니다.

문체는 합니다체로 통일합니다(`docs/techreport/`, `docs/guidelines/`가 합니다체입니다). 표와 목록의 항목은
명사형으로 끝내도 됩니다.

## 1. 대부분의 맥락에서 어색한 표현

한국인 독자에게 어색하게 들리거나, 번역투나 AI가 쓴 글처럼 읽히는 표현입니다.

| 쓰지 않음 | 대신 | 이유 |
|---|---|---|
| 꼬리 (분포의 tail) | `tail` 그대로, 또는 의미에 맞게 entropy 등 | 한국어 문서에서 분포의 tail을 "꼬리"라고 쓰면 어색합니다 |
| "A는 B 하나다", "A는 B 중 하나다" (강조 용도) | "A는 B다" | "하나"를 강조로 쓰면 외국인이나 AI가 쓴 문장으로 읽힙니다. 실제로 여러 개 중 하나라는 뜻일 때만 씁니다 |

## 2. 코딩·연구 맥락에서 어색한 표현

| 쓰지 않음 | 대신 | 이유 |
|---|---|---|
| 조용히, 경고 없이 (silently, without warning의 번역) | 뺍니다 | 강조 부사로만 읽힙니다. 문장에서 빼도 뜻이 그대로입니다 |
| "A가 아니라 B다" | "B다" | 아무도 A라고 하지 않았는데 A를 부정하는 문장입니다. "A가 아니라" 부분을 뺍니다. 앞 문장이나 인용한 문헌이 실제로 A라고 했거나, 이 문서가 A라는 가설을 세웠다가 기각한 경우에는 둡니다 |
| 규칙 (코드의 작동 방식이나 로직을 가리킬 때) | 무엇을 하는지 직접 씁니다: "~이면 ~한다", "~로 계산한다" | 코드가 어떻게 동작하는지를 "규칙"이라고 부르면 어색합니다 |
| 닫다, 닫힌, 열린 ("문제가 닫혔다", "루프가 닫힌다", "열린 질문") | 여지가 있다 / 없다, 불확실하다 | 이슈 트래커의 open / closed를 옮긴 번역투입니다. "이 방향은 더 볼 여지가 없다", "원인은 아직 불확실하다"처럼 씁니다 |

## 3. 대부분의 경우 더 나은 단어

| 쓰지 않음 | 대신 | 그대로 두는 경우 |
|---|---|---|
| 판정 | 평가 | 통과 / 탈락을 정하는 뜻이면 "통과 여부" |
| 모드 | `mode` 그대로, 통계의 mode면 최빈값 | |
| load-bearing | 필수 | |
| 싼 (계산이 싸다) | 비용이 낮은, 가벼운. 같은 결과를 더 적은 비용으로 낸다는 뜻일 때만 "효율적인" | |
| 검증 | 확인 | validation의 뜻(검증 세트, 검증 손실)과 교차 검증 |
| 양 (gradient의 양, 변화량 등 크기를 말할 때) | 크기 | 개수나 분량(데이터의 양) |

## 예시

- 고치기 전: "이 tail의 꼬리 부분에서 gradient가 커진다." → 고친 후: "σ 분포의 tail에서 gradient가 커집니다."
- 고치기 전: "step 0은 layout을 잃는 가장 큰 단계 하나다." → 고친 후: "step 0에서 layout을 가장 많이 잃습니다."
- 고치기 전: "base GPTQ를 쓰면 bake된 delta가 조용히 사라진다." → 고친 후: "base GPTQ를 쓰면 bake된 delta가 빠집니다."
- 고치기 전: "캐시가 경고 없이 무효화된다." → 고친 후: "캐시가 무효화됩니다."
- 고치기 전: "레벨을 정하는 것은 noise가 아니라 objective다." → 고친 후: "레벨은 objective가 정합니다."
- 고치기 전: "merge는 adaLN을 평균하는 규칙을 따른다." → 고친 후: "merge는 adaLN을 평균합니다."
- 그대로 둠: "DMD는 궤적이 아니라 분포를 맞춥니다." (앞 문단이 궤적을 맞추는 증류를 설명한 경우)

## 확인

다 쓴 뒤 아래 패턴으로 검색해 남은 것을 고칩니다. `양`, `하나`처럼 한 글자나 흔한 낱말만으로 검색하면
"다양성", "양쪽", "LoRA 하나"가 대부분이므로 조사와 어미를 붙여 찾습니다.

```
grep -nE '꼬리|조용히|경고 없이|규칙|닫[히혔힌]|열린|판정|모드|load-bearing|검증' <문서>
grep -nE '하나(다|입니다|였다|였습니다)|중 하나' <문서>
grep -nE '[가이] 아니라' <문서>
grep -nE '(의|는|은) 양[이을은과도 ]|[^다]양(이|을) (크|작|늘|줄)' <문서>
```

검색에 걸린 것은 위 표의 "그대로 두는 경우"에 해당하는지 본 뒤 고칩니다.
