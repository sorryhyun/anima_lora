T-LoRA

타임스텝 의존 랭크 마스킹. 디노이징 타임스텝에 따라 유효 LoRA 랭크가 거듭제곱 스케줄로 변동:
• 높은 노이즈 (초기 스텝) → 축소된 랭크 (min_rank까지)
• 낮은 노이즈 (후기 스텝) → 전체 랭크 (최대 표현력)
구도·포즈·인물 등 구조가 결정되는 구간이 곧 파인튜닝이 암기를 일으키는 지점이므로, 그곳에서는 표현력을 억제하고 스타일 디테일을 학습하는 깨끗한 쪽에서 전체 랭크를 개방합니다. 마스크는 학습 시에만 적용되며 추론은 모든 t에서 전체 랭크를 사용하므로, 저장된 .safetensors는 베이킹 가능한 일반 LoRA입니다. docs/methods/timestep_mask.md 참조.

토글: use_timestep_mask = true.

변형
• tlora — 일반 LoRA 위의 T-LoRA (SVD-Down 초기화, use_timestep_mask = true). 기본 베이킹 가능 조합 — σ별 랭크 스케줄링. 완전히 베이킹 가능합니다.
• tlora-8gb — 동일한 아키텍처, 저VRAM 프로필 (그래디언트 체크포인팅 + 오프로드). 기본 변형에서 OOM이 발생하면 선택하세요.
