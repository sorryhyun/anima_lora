Preprocessing

Two artifact lanes feed training:

1. Caching — resizes each image to a native-aspect size inside its tier's token band (no crop) and tokenizes captions through Qwen3 + T5, writing {stem}_{WxH}_anima.npz latents and {stem}_anima_te.safetensors sidecars. When shuffle variants > 0, each TE cache holds N captions and the dataloader samples one per training step (turn on use_shuffled_caption_variants in your method config to use them).

2. Masking — runs SAM3 once per mask rule (each rule has its own text prompts and path pattern) into a tempdir, then merges the passes into post_image_dataset/masks/<rel>/{stem}_mask.png. Masks are used only when masked_loss = true in the method config; a mask dir on disk does not enable masking by itself.
