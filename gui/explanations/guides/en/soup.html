Soup

Uncond-init ΔW soup — a quality-and-robustness recipe for a LoRA over any glob slice of the dataset, not a new adapter family. Its output is an ordinary bakeable LoRA (output/ckpt/anima_soup_<slug>.safetensors).

Three phases. (1) A short caption_dropout_rate 1.0 uncond inter-train on a diluted pool (the Pool pattern in the form, default * = whole dataset; your fine-tune selection is always unioned in) — a shared, deterministic checkpoint reused across every soup drawing the same pool. (2) N seeded fine-tunes on your Path pattern images, initialised from that uncond checkpoint. (3) An exact ΔW soup of those fine-tunes, SVD-truncated back to network_dim.

What it buys you. A quality win plus seed-lottery insurance: a soup of 3 fine-tunes lands at roughly the best single ingredient, so a bad seed draw can no longer sink the run. Rank-16 SVD truncation is near-free (~99.9% energy retained). It is not a memorization fix.

Requirements. Plain-LoRA checkpoints only (Hydra / Chimera are refused). Path pattern is required — a fnmatch glob (| separates alternatives, e.g. sincos/* or art_a/*|art_b/*) matched against each image's path relative to its subset image dir. The uncond pool must stay broader than the fine-tune set so the target is a minority share (the default * pool ensures this). The pool, soup count (num_soup) and rank knobs (in the [soup] section below) have defaults. Runs as one daemon command job (the pipeline drives its own train.py phases). See docs/experimental/soup.md and scripts/soup/.
