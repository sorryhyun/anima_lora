CJK Renderable Anima

Anima already knows how to draw Japanese glyphs. It garbles them because nothing in the text stream tells it which glyph to draw. This line trains that missing address: one free vector fr per vocab-pack ext row, with the DiT, adapter and text encoder all frozen. What ships is the pack, with the trained rows baked in.

The loss: a paired difference, not a plain residual

Binding one row takes exposure: ≈ 1 000 composite draws. The paired loss changes what each of those draws teaches. The row is trained on what separates the two renders, so it learns to put its glyph into the scene it is given.

Where it lands: the frozen text path

Both branches run through this path with the same frozen weights. One thing moves: the ext-row table the T5 id stream reads, and it moves only through branch B's caption.

The address, written out

One table is trained: the ext rows that llm_adapter.embed reads, one free vector per row. Notation: bold lowercase is a vector, bold uppercase a matrix or tensor, italic a scalar.

The hook exists only while training. Afterwards each trained vector is added into its pack row, ext_embed[r] += ρ · f_r, and what ships is an ordinary vocab pack.

How it is trained: pack → step 1 → step 2 → bake

One table, grown in stages. Step 1 binds single glyphs; step 2 adds punctuation, words and sentence order to the same rows; the bake writes the result into an ordinary pack. Only the table passes between stages.

What it sees, what it draws

Every item is a scene composite. The base model draws a character scene with an English speech bubble or sign, the anchor text is erased with the bubble's own colour, and the Japanese text is drawn into the cleared region in one of 16 manga faces. The caption is the scene's own tags with the quoted string swapped, under the frame the scene was drawn with.

Why a row, not a script

A row is an address, not a shape coordinate. Nothing about how a glyph looks predicts which direction it gets, so every row has to be bound on its own: ≈ 1 000 composite draws.

A row can be a whole word: Qwen merges します into one piece and the DiT draws it as one unit. But a sequence of trained rows still renders as one unit, while the same frozen stack reads pretrained English sequences in order. Closing that gap is the sentence line: Manga109 dialogue drawn into sentence-anchored scenes, continuing from the singles table.

Why it is hard: the row → glyph map is a hash

Every shortcut assumes a glyph's shape predicts its row: smoothness, linearity, a metric, a shared codebook. None of it is there. The frozen stack reads a row as one unit and any near-orthogonal direction will do, so the only thing that binds a direction to a glyph is the gradient sent back while the model draws it.

The other half is already in the weights: kana, kanji atoms, Hangul syllables and simplified hanzi all render from rows alone, so nothing has to be added to them.

The cost is exposure. KO and ZH need no new mechanism: ordinary new rows, paid for at the same rate.

Inventory choice is the other half: the 11 172 Hangul syllables are the headache; KS X 1001's 2 350 cover everyday text.
