# 1112_v1: the 4-step setup for the first 1000-iteration run

Written 2026-11-12, after the step-0 arms and the length / LR probes (`reports/step0.md`). The
baseline is arm 0's control, `configs/1112_0833.toml`, on the merged14 soup teacher. v1 is that
baseline with four changes. The run has not started; its config takes its id at submit time.

## v1 against the baseline

| Field | Baseline (`1112_0833`) | v1 |
|---|---|---|
| `iterations` | 250 | **1000** |
| `optim.lr_schedule` | `constant` | **`cosine`** (2 % warmup, 5e-5 → 5e-6) |
| `ema.window` | 0.2 of the updates (50) | **0.2 of the summed LR** (about the last 450 updates) |
| `dpdmd.dm_first_step` | off | **on**, anchor kept |
| `io.save_every`, `validate_every_n_steps` | 125 | 250 |

Everything else is the baseline: merged14 on int8 + fp32 stream, `teacher_cfg 4`, rank 64 / alpha
180 with adaln 16 / 90 and `weight_svd` init, 4 steps at shift 3 with `dynamic_schedule`, the anchor
at `div_weight 0.1` and `k_anchor 6` of 12 with one ε per iteration, DMD + CDM 1.0 + GAN token head
0.03, `fake_transition`, 4 fake steps per student step after a 200-step fake warmup, LR 5e-5 for
student and fake, `grad_clip 1.0`, batch 1, seed 42. The EMA is what ships.

Cost: S-c.1 ran this loop at 5.75 s per iteration, so about 100 min.

## Why each change

**1000 iterations on a cosine LR.** The fit of step 0 follows the LR at the end of training, not the
length. On the constant 5e-5 the held-out anchor MSE stays at 0.14–0.18 from 250 to 1000 iterations
(`1112_1336`: 0.165 / 0.143 / 0.155 / 0.140). Annealing only the last 250 iterations takes the same
run to 0.123 (`1112_1410`), and the two 500-iteration cosine students sit at 0.109 / 0.118. Four
anchor draws and an average of checkpoints do not do this (0.147, 0.156). The length is the user's
call for a first full-size LoRA; steps 1–3 random-walk from about iteration 125 on the constant LR
(`reports/arm0.md`), and the cosine spends 55 % of the constant run's summed LR.

**EMA span in summed LR.** Under the cosine the last 20 % of the updates carry about 5 % of the
weights' movement, so an EMA counted in updates would be the raw final. The span is now a share of
the summed LR (`AdapterEMA.step(rate)`, each update decays by `decay ** (lr / mean lr)`), which keeps
the averaging the constant-LR EMA 0.2 did. On the constant LR nothing changes. For steps 1–3 the
anneal only shortens the walk; the EMA is what averages it.

**`dm_first_step` on.** The regression alone does not give the layout at any fit reached so far: at a
held-out MSE of 0.127 the trained step 0 moves the probe by +0.04 / +0.05 over the students' own and
stays 0.14–0.18 under the anchor target. The DM signal on step 0 is the one change that moved
composition in the renders (S-c.1: the guitarist's pose goes to the jump on every seed). User's read:
improved, less diverse. This is the change to watch, below.

## Read of the run, fixed before it starts

- **Renders are the gate.** The EMA at 250 / 500 / 750 / 1k on `bench/turbo/judge_hard.txt`, seeds
  1–4, beside the teacher, the control and the twin (`1112_0833`, `1112_0834`) and S-c.1's EMA 250.
- **Diversity.** Across the four seeds of each prompt, and `val/div_ac_sim` at each save against
  S-c.1's 0.68 / 0.55 (125 / 250) and arm 0's 0.68 / 0.59. S-c.1's EMA 250 already draws one apron
  colour on all four café seeds. DP-DMD's Fig. 5 shows the same trade for a DMD gradient that reaches
  the first step: preference up, diversity down.
- **Probe beside the renders.** Held-out anchor MSE of the EMA 1k (the cosine students: 0.11–0.12;
  S-c.1 at 250 on the constant LR: 0.18), and `S` / `T>S@1` / `A>S@1`. `S` scores closeness to the
  teacher's image of the same noise, which the DM signal does not aim at, so it does not gate.
- If the renders gain against the control and diversity holds at S-c.1's level, v1 is the control
  for the arms in `plan.md`. If diversity falls with the length, the second run is v1 with
  `dm_first_step` off, and the earlier EMA saves say where it started to fall.

## Kept from the baseline

| Part | Evidence |
|---|---|
| The anchor as the step-0 target, `k_anchor 6` of 12 | S-a: a step 0 at zero anchor loss keeps the view from below (`A>S@1` 0.67 / 0.73 against `S` 0.46 / 0.54); the chord to σ 0.75 costs 0.02–0.07 |
| The anchor stays on with `dm_first_step` | with it off the loop collapses by step 250 (`reports/mfd.md`) |
| `div_weight 0.1` | S-b: the anchor alone fits step 0 no better than the joint recipe, so step 0 is not losing to the DM / CDM / GAN terms |
| One ε per iteration for the anchor | S-c.2 and `1112_1336`: 250 iterations at four draws and 1000 at one land on the same level |
| Peak LR 5e-5 | S-b2: 2e-4 fits step 0 worse than no training (0.277 against 0.171). 2-step: the LR scales the walk and not its onset (`reports/walk.md`) |
| `fake_transition`, CDM 1.0 | no harm at 500 iterations (`vatdm.md`); CDM keeps the sky (`reports/mfd.md`) |
| GAN `weight_gen 0.03` | GAN-off probe: the walk without GAN is the same walk (`reports/arm0.md`) |
| `dm_draws 1`, `grad_accum 1` | null against the level on 2 steps (`reports/walk.md`) |
| The EMA ships, raw checkpoints do not | a burst lands about once per 250 iterations on the constant LR and the control's raw 250 sits inside one (`reports/arm0.md`) |

## Left out of v1

| Change | Why |
|---|---|
| Step-0 warm start from an anchor-only run | the anchor-only run reaches 0.123–0.127 with an annealed tail; the joint cosine students reach 0.109–0.118 without a warm start |
| Anchor draws in the joint loop | no gain over the same number of pairs spent as iterations; about 1.6 s per extra draw |
| More length on a constant LR | `1112_1336`: flat from 250 to 1000 |
| Checkpoint averages for the step-0 fit | the exact average of raw 500 / 750 / 1k reads 0.156 |
| Student LR 2e-4 | S-b2 |
| A step-0-only adapter | S-b is one; no gain, and it breaks the one-LoRA ship |
| An anchor that ends at the student's first boundary | the chord costs 0.02–0.07 (S-a) |
| σ_a normalisation of the DM loss | arm 0's top / bottom norm ratio is 1.43, under the 1.5 line fixed beforehand |
| DAVE on the student's step 0 at inference | parked: a hook does not bake into the LoRA |
