# One 2× upsample stage in the head (`convnext_1119_1106`, `mangaup_1119_1152`, 2026-11-19)

## convnext_1119_1106 — the user's arm

### Facts

Parent `convnext_1119_0938` (`--no_skip --ls_init 1.0`), `--up 1`: blocks 1–2 at token resolution
(width 1024) as before; the third block runs after one 2× upsample (LayerNorm + per-token linear
1024 → 4 × 512, pixel shuffle) at width 512, so its 3×3 depthwise sits at 8-px spacing, and `out`
writes an 8×8 patch per upsampled position (512 → 192) in place of 16×16 per token (1024 → 768).
Same multiplies in the third block's MLP; 24.9M parameters. Data, order, noise seeds,
LR 2e-4, 4 updates per rollout, 3600 rollouts, cosine, clip 1.0 unchanged.

Question set before the run: does a block at 8-px spacing pass `0938` on test / text and take out
the softness left in thin lines, small text and screentone? Above → the upsample stage joins the
recipe. Level → `0938`'s head stays and capacity goes to width or data. Bars: spread unknown (no
seed twin of `0938`).

Result: 26 min, 0.43 s / rollout. `bench/pixel_readout/results/20261119-1151-convnext_1119_1106/`
(local). Test PSNR vs VAE(x0), dB:

| rollout 600 / 1200 / 1800 / 2400 / 3000 / 3600 | test (30) | text (8) |
|---|---|---|
| `0938` | 25.69 / 29.39 / 31.01 / 32.21 / 32.64 / 32.93 | 22.63 / 25.14 / 26.21 / 26.99 / 27.36 / 27.45 |
| `1106` | 26.94 / 30.57 / 31.73 / 32.89 / 33.44 / 33.64 | 23.47 / 26.01 / 26.93 / 27.62 / 27.96 / 28.04 |

- Per image, `1106` − `0938`: test +0.31 … +1.31 (30 / 30 up), text +0.42 … +0.87 (8 / 8 up).
- Claude's read (labelled, VAE | 0938 | 1106 crops of text 00, 02 and sheet 08): balloon glyph
  strokes sharper with `1106`, closer to the VAE.
- Adopted into the recipe (Claude's call under the user's proceed-unless-flagged rule).

### Interpretation

Every image moved up, so the gain is not carried by a few images, though without a seed twin its
size is not separated from run noise.
