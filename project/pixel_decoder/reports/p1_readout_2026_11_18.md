# P1: a per-token linear readout from the DiT's pre-head features (`readout_1118_2219`, 2026-11-18)

## Facts

Script `bench/pixel_readout/linear_probe.py`. Question set before the run: does a per-token linear
map from the features `final_layer.linear` reads (2048-dim, LayerNorm + adaLN-modulated) to a
16×16 RGB patch reproduce the VAE decode on Anima? Recognisable → a ConvNeXt head (P2). Not
recognisable → the line stops.

Per image: VAE-decode the cached clean latent (target), noise it to σ 0.0577 (last σ of the
50-step shift-3 grid), one DiT forward with the cached caption, tap the final layer's input.
Ridge least squares on 256 train images; scored on 30 images from 8 artists held out of the fit.
Reference: the VAE image averaged per 16×16 patch and upsampled (one colour per token).
Anima-base, 2.4 min, teacher-forced (real latents at σ_last). Results
`bench/pixel_readout/results/20261118-2221-readout_1118_2219/` (local), with
`readout_linear.safetensors`.

| | test PSNR vs VAE (dB) |
|---|---|
| linear readout (ridge 1e-6) | 26.28 |
| token mean, bilinear | 22.07 |
| token mean, nearest | 21.57 |

- Linear above token-mean bilinear on 30 / 30 test images (+2.6 … +6.4 dB). Ridge 1e-4: 26.13;
  1e-2: 24.83.
- Text images (8, added in P2's eval): 21.61.
- The user's read: "진짜 잘나오네".

## Interpretation

The last-layer features carry the image well enough for a linear map to get the layout and colour,
so the line went on to P2. What a per-token map cannot fix is anything that crosses a patch border.
