# cjk_aware_anima_dit — CJK semantics on the DiT side

DiT-side CJK line. Successor to [`../cjk_aware_anima/`](../cjk_aware_anima/)
(encoder side, frozen 2026-09-05). Frozen 2026-09-08, wake line split out
2026-09-14, moved to `finished/` on 2026-09-24 (from its old home directly
under `project/`; the one reader the wake line still imported, the stock
VL16 sweeper, was lifted into `cjk_renderable_anima/src/common/readers.py`
first). Premise: ext rows are content-free addresses; what a CJK address
*means* has to be learned or woken on the DiT side.

## Verdicts

[`findings.md`](findings.md) is the record, read-only. The short form:

- **Shipped (the OCR half).** The AnimeText detector and the B′ SFX reader
  (`sorryhyun/paddleocr-vl-1.6-manga-lora`), both wired as
  `anime_tools.ocr.{animetext,sfx}`; the caption clause rules; the D1
  quote-partitioned pack.
- **Ceiling (the reader).** Five arms decoupled in-domain COO from the doujin
  gate; the headroom left is ♡ / small-kana labels, not representation.
- **Handed off, not measured (the DiT half).** G-A (unmasked training at
  corpus scale) was read only on one 351-image shard, where the caption
  clauses tie; G-B (a LoRA learning CJK tag meaning) was never run. The
  DiT question continues as the wake line
  [`../../cjk_renderable_anima/`](../../cjk_renderable_anima/README.md) and the
  production line [`../../cjk_anima_scale/`](../../cjk_anima_scale/README.md);
  neither is a verdict on G-A / G-B.
- **Open remainder** — the reader label pass, R3 / R4.4, heart positives, a
  KO / ZH gate set, the S0b reader-disagreement pass: `findings.md` § Still
  open outside the wake line. None is owned by an active line.

## What is where

- [`findings.md`](findings.md) — **read first.** Every settled verdict in the
  form a decision needs, one screen per topic: comparability (the sincos
  gate changed units twice — no `/ 71` figure converts to `/ 617`), the
  reader ledger, ext rows / pack / DiT, captions, the SFX reader, detection,
  gotchas, the do-not-re-propose list, and the open items outside the wake
  line.
- [`../../cjk_renderable_anima/reports/`](../../cjk_renderable_anima/reports/README.md) — moved with the wake line (2026-09-14; the frozen copy here is archived). Was the live plan (W2d encoder → W3 strings →
  W4 kanji), gates and kill criteria.
- [`history.md`](history.md) — the dated per-phase record (D0 … the wake
  probes) with every evidence pointer, verbatim as it was written. Go here
  for how a verdict was reached.
- [`eval.md`](eval.md) — the OCR reader scoreboard on one basis, generated by
  `ocr/eval_table.py`. [`whitespace_fixed.md`](whitespace_fixed.md) — the
  target-normaliser note `ocr/crop_dataset.py` cites.
- `ocr/`, `probes/`, `render/`, `assets/` — this line's code, runnable by
  path (`python project/finished/cjk_aware_anima_dit/ocr/eval_table.py`).
  The hand labels (`assets/sfx_labels_sincos.tsv`, 975 rows / 617 SFX scored)
  are the reader gate's ground truth.
  **`probes/wake_probe.py` (+ `wake_geometry.py`) here is frozen** — the
  single-file ancestor of the wake instrument, last touched 2026-09-14 when
  the line moved. The live instrument is the split package
  [`../../cjk_renderable_anima/src/`](../../cjk_renderable_anima/src/)
  (`wake_probe.py` entry point + `stages.py` + role packages); every run since is
  there. Read this copy only for how a pre-split run was invoked.
- `reports/` — dated reports, gitignored (private mirror); the wake report
  `wake_w0_w2_2026_09_13.md` is there. Reports and the eight plan files from
  before the freeze are under `_archive/cjk_aware_anima_dit/{reports,plans}/`.
- The paired-edition manga corpus lives in an external private checkout that
  is never named or pathed here; it never entered the training work.
