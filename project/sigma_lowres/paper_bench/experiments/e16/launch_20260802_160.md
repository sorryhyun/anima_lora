# E16.0 launch — 2026-08-02 (5 deterministic twins, hews, seed 1001)

## Design amendment vs the proposal README

The placement arms run the 768 route **unconditionally**
(`--sigma_lowres_threshold 0.0`, no yarnsig — the unsafe768 arm
configuration), NOT under the σ>0.5 gate. Rationale (user decision,
2026-08-02): E14's ledger now measures the 768 route's per-σ bias
structure directly (B/C decomposition on the full 15-bin grid), so 16.0
does not need the σ-gate riding along — the span gate alone controls
placement, the eligible set is trivially *all* steps (arm-invariant with
no CRN caveats), and the unconditional route maximizes the bias per
step (E4: unsafe768 is the strongest ΔW deviation) ⇒ best ordering SNR.
Consequence: each placement arm demotes ~240/480 steps (half of ALL
steps), not ~122 (half of the σ>0.5 eligible set).

## Trainer delta (landed this session)

`--sigma_lowres_span MODE[:FRAC]` — step-span gate on top of the σ
gate (`train.py::_sigma_span_params/_sigma_span_allows`, wired into
`_maybe_sigma_demote`):

- `early[:f]` — demote only in the first f·T train forwards (default 0.5);
- `late[:f]` — only the last f·T; boundary at round((1−f)·T) with the
  same rounding as early's, so early:f / late:1−f partition [1,T]
  exactly for any T;
- `spread[:p]` — per-step coin seeded from `--seed·1_000_003 + step`
  alone (python `random.Random`, touches neither the global nor the
  paired torch streams — CRN pairing holds).

T = `max_train_steps × gradient_accumulation_steps`; the step index
counts every sigma_lowres train forward (off-route batches included).
The σ draw itself is never skipped (σ marginal untouched). Pinned by
`tests/test_sigma_lowres.py::TestSigmaSpan` (parse/guards, exact
early/late partition ±1 mass at odd T, coin determinism + stream
independence, grad-accum scaling).
