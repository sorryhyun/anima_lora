## 1. 系统要求

| 项目 | 最低 | 推荐 |
|---|---|---|
| GPU | **RTX 3060 及以上**（20xx 系列及以下无法使用） | 显存 16 GB 以上 |
| 系统内存 | 16 GB | 32 GB 以上 |
| 硬盘 | 60 GB 可用空间 | 200 GB 以上（缓存 + 输出累积） |
| 操作系统 | Windows 11 / Ubuntu 22.04+ | Ubuntu 24.04 |
| Python | **必须为 3.13** | - |
| NVIDIA 驱动 | **595 及以上**（CUDA 13.x 要求） | - |

## 2. 安装

在 PowerShell 中粘贴下面这一行。它会自动安装 `uv`、CUDA 13.2、Python 3.13 和全部依赖，完成后 **自动打开 GUI**。

```powershell
irm https://raw.githubusercontent.com/sorryhyun/anima_lora/main/install.ps1 | iex
```

- 安装位置为 `.\anima_lora\`（可用 `$env:ANIMA_DIR` 修改，用 `$env:ANIMA_VERSION='v1.4.0'` 固定版本）。
- **如果提示需要重启**（CUDA 安装后很常见），重启后再次运行同一条命令 — 会从中断处继续。
- 之后请通过桌面的 **"Anima LoRA GUI"** 快捷方式启动。

安装完成后，在 GUI 中按 **§3 → §4 → §5** 的顺序进行即可。

> 如果想自己 `git clone`，或自动安装失败，请参阅 [附录 B](#附录-b-手动安装-uv--git) / [附录 C](#附录-c-cuda-手动安装)。

## 3. Hugging Face 登录与模型下载

### 3.1 登录

1. 在 <https://huggingface.co/settings/tokens> 创建一个 **read** 权限的令牌。
2. 将令牌粘贴到 GUI 的 **Hugging Face 登录** 输入框。

令牌保存在 Hugging Face 标准缓存中，因此 GUI 与 CLI 共用同一份登录信息。

### 3.2 下载模型

在 GUI 的 **Models** 对话框中，一个按钮即可下载以下三项。

| 文件 | 路径 |
|---|---|
| Anima DiT（扩散模型本体） | `models/diffusion_models/anima-base-v1.0.safetensors` |
| Qwen3 0.6B 文本编码器 | `models/text_encoders/qwen_3_06b_base.safetensors` |
| QwenImage VAE | `models/vae/qwen_image_vae.safetensors` |

同时还会下载 **SAM3** 与 **MIT** 检查点。这两者仅用于可选的蒙版损失功能（[§7.4](#74-蒙版损失排除文字气泡)）。

> **SAM3 是受限（gated）模型。** 需要先到 <https://huggingface.co/facebook/sam3> 点击 **Request access** 并等待批准（几分钟到几天），在此之前下载会以 403 失败。上述三个核心模型 *不是* 受限模型，且下载不会因 SAM3 失败而中断，所以在等待批准期间也可以开始训练。
>
> 如果下载频繁中断，请用 [附录 A](#附录-a-cli-使用方法) 中的单独目标分批下载。

## 4. 数据集准备

结构为 *图片 + 同名 `.txt` 描述词 sidecar*。原图放在 `image_dataset/`（子文件夹随意）。

```
image_dataset/
├─ 00001.png
├─ 00001.txt
├─ 00002.jpg
├─ 00002.txt
└─ subfolder/
   ├─ 00010.webp
   └─ 00010.txt
```

### 4.1 描述词编写提示

按照 Anima 官方指南，标签顺序始终为 `[meta] [character] [series] [artist] [general]`。

```
absurdres, safe, 1girl, chitanda eru, hyouka, @channel (caststation), full body, serafuku, She is saying hi.
```

- 根据实测，`absurdres`、`highres`、`masterpiece` 等**质量标签最好不写或只保留最少量**。（今后正式发布 mod guidance 后可以完全不写。）
- **不想手写描述词？** 在 GUI 的 **Dataset** 标签页选中图片并点击 **Autotag**，内置的 **Anima Tagger** 会按正确顺序填好描述词（[§6.3](#63-dataset-标签页autotag--grouping)）。但不要直接照用 — 训练前请检查标签，尤其是角色/系列/画师名称。

## 5. 预处理

为了优化训练速度与显存，需要预先完成 **缩放 → VAE 潜变量缓存 → 文本嵌入缓存**。在 GUI 的 **Preprocess** 标签页点一个按钮即可完成三个步骤。

| 步骤 | 作用 | 输出 |
|---|---|---|
| 缩放 | 按 VAE 要求的像素对齐调整尺寸，为每张图片分配固定 token 分桶，并排除过小的图片（默认低于 0.5 MP） | `post_image_dataset/resized/` |
| VAE 潜变量缓存 | 只运行一次 VAE 并保存结果 → 训练时无需把 VAE 放到 GPU 上 | `post_image_dataset/lora/{stem}_{WxH}_anima.npz` |
| 文本嵌入缓存 | 预先计算 Qwen3 0.6B + LLM 适配器输出（含描述词乱序变体） | `post_image_dataset/lora/{stem}_anima_te.safetensors` |

PE 视觉特征缓存（`{stem}_anima_pe.safetensors`）是仅 CMMD 验证需要的可选步骤。

> **⚠️ 缓存会被复用，且绝不会自动删除。**
> 重新运行预处理时，已有的 `.npz` / `_te.safetensors` / `_pe.safetensors` 既不会被覆盖也不会被删除，只会处理**缺失的条目**。因此重跑非常快，中途中断也安全。
>
> - **添加了图片** → 直接重新运行即可。
> - **修改了描述词** 或更改了分词器/缩放选项 → 单纯重跑不会生效。请手动删除缓存目录（`post_image_dataset/lora/`）后重新运行。

## 6. GUI 使用方法

在一个窗口内完成配置编辑、数据集浏览、预处理、训练启动/监控以及 LoRA 合并。

- **训练配置 (Training Config)**：在变体下拉框（推荐 `tlora`）和 **Hardware** 下拉框（Default 16GB+ / Low VRAM 8GB）中做出选择，修改训练参数后直接开始训练。数据范围（`sample_ratio`、`artists_shard`）是基础 (Basic) 区域中的普通输入字段。
- **预处理 (Preprocess)**：一次完成缩放 + VAE + 文本嵌入缓存。
- **数据集 (Dataset)**：预览与编辑图片/描述词、Autotag、Grouping（[§6.3](#63-dataset-标签页autotag--grouping)）。
- **合并 (Merge)**：把训练好的 LoRA 烘焙进基础 DiT，保存为 ComfyUI 独立检查点（仅支持基础 LoRA / OrthoLoRA / T-LoRA）。

GUI 读取 `configs/gui-methods/<variant>.toml`（每个变体一个独立文件）并在内部调用 `train.py`，因此同样的配置也可以在 CLI 中复现（[附录 A](#附录-a-cli-使用方法)）。

### 6.1 表单编辑与保存行为

训练/预处理子进程会重新从磁盘读取 variant TOML，所以只改表单而不保存就不会生效。GUI 用两种方式处理这一点：

- **变更检测**：编辑任意字段（或 `+ Extra args` 文本框）后，`Save` 按钮会变成橙色的 `Save *` — 表示 *屏幕与磁盘不一致*。
- **自动保存**：即使忘记保存就按下 `Train` / `Preprocess`，当前表单值也会先写入 variant 文件再启动子进程。也就是说 **屏幕上看到的值就是实际训练用的值**。（`Test` 使用最后的检查点推理，因此不在自动保存范围内。）

> 想放弃修改，请切换到别的 variant 再切回来 — 会从磁盘重新加载，编辑被丢弃。

### 6.2 停止训练与关闭 GUI

训练并不在 GUI 窗口 *内部* 运行 — 按下 `Train` 后，任务会交给以分离进程方式运行 `train.py` 的后台 **训练守护进程**。

- **`Stop` 按钮只中断当前任务。** 守护进程仍在运行，并继续处理队列中的下一个任务。
- **关闭 GUI 不会停止训练。** 重新打开后会自动重连到正在运行的任务（`Re-attached to running job …`），进度条和日志实时接续。适合通宵运行的长时间训练。
- 例外：**`Test` 和 `Preprocess` 是窗口内的子进程**，关闭 GUI 会取消它们。
- 要彻底停止训练并释放 GPU，需要使用 CLI 的 `make daemon-terminate`（[附录 A](#附录-a-cli-使用方法)）。

### 6.3 Dataset 标签页：Autotag & Grouping

**Autotag — 自动生成描述词。** 选中图片并点击 **Autotag**，**Anima Tagger** 会按 `[meta] [character] [series] [artist] [general]` 的顺序预测标签并填入描述词框。首次点击需要下载 tagger 模型，会花一点时间；之后模型常驻后台，后续图片几乎瞬时完成。在启动其他 GPU 任务前，tagger 会自动释放显存。

**Grouping — 相似图片聚类。** 点击 **Group** 会把近乎重复、或呈现同一场景/角色的图片聚成一组，在图片列表中折叠为**绿色分组标题**。可用于剔除重复图或调整各概念的占比。

- 它比较的是 *视觉内容* 而非文件名或描述词，并且按 **顶层文件夹**（画师/角色分桶）计算分组，因此不同文件夹的图片不会被合并。
- 会复用缓存的图像特征，所以添加图片后随时再次点击 **Group** 的成本都很低。

> 两个功能都作用于 **原始** `image_dataset/` 图片，不影响预处理缓存 — 请在预处理 *之前* 运行以整理描述词。

## 7. 训练

配置合并顺序为 `configs/base.toml → configs/presets.toml[<preset>] → configs/methods/<method>.toml → CLI args`，且 **method 设置会覆盖 preset 设置**。

最推荐的起点是 **OrthoLoRA + T-LoRA（`tlora` 变体）** — 稳定性、细节与风格保持之间最均衡，普通的角色/风格 LoRA 可以直接使用。在 GUI 中只需选择变体下拉框的 `tlora` 和 Hardware 下拉框即可。

### 7.1 常用参数（以 LoRA 默认值为例）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `network_dim` | `32` | LoRA 秩。越大表现力↑，参数量↑ |
| `network_alpha` | `32` | LoRA 缩放（通常与 `network_dim` 相同） |
| `learning_rate` | `2e-5` | 学习率。Hydra 可以再低一些 |
| `max_train_epochs` | `4` | 数据集越小，epoch 越多 |
| `save_every_n_epochs` | `2` (gui-methods) / `4` (methods) | 适配器权重的累积保存间隔 |
| `checkpointing_epochs` | `2` (gui-methods) / `4` (methods) | 恢复状态的保存间隔（覆盖单个文件） |
| `caption_dropout_rate` | `0.1` | 将部分描述词替换为空字符串（有助于 CFG） |
| `use_shuffled_caption_variants` | `true` | 使用描述词逗号乱序变体 |

变体开关（`use_ortho`、`use_timestep_mask`、`use_moe_style`、`router_source` 等）已在各变体文件中设置好。推荐的 `tlora` 即 `use_ortho = true` + `use_timestep_mask = true` 的组合。

### 7.2 自动恢复 (checkpointing_epochs)

训练中断后可以 **从最后保存点自动继续**。停电、OOM、误关窗口等情况都能应对，默认已启用。只需再次点击 `Train`，日志中出现 `auto-resuming from checkpoint at step N` 即表示恢复正常。

它与 `save_every_n_epochs` 的职责不同：

| 键 | 保存内容 | 累积？ | 用途 |
|---|---|---|---|
| `save_every_n_epochs` | 适配器权重（`anima_lora-000004.safetensors` 等） | **累积**（可用 `save_last_n_epochs` 限制） | 用中间结果推理、比较过拟合时点 |
| `checkpointing_epochs` | 用于恢复的完整状态（优化器 / 调度器 / RNG / 权重） | **覆盖单个文件**（磁盘不会膨胀） | 中断后继续训练 |

- 训练正常结束后，恢复用的临时文件会自动删除，只保留最终产物。
- **如果修改了数据集或核心设置（秩、LR、epoch 数等）**，从旧状态恢复没有意义甚至有害。请手动删除 `output/ckpt/<output_name>-checkpoint-state/` 文件夹后重新开始。

### 7.3 输出物

- 训练好的权重：`output/ckpt/<output_name>.safetensors`（按变体自动分为 `anima`、`anima_tlora_ortho`、`anima_hydra`、`anima_postfix` 等）
- 中间检查点：`output/ckpt/`（带 `.snapshot.toml` sidecar；Hydra 还有 `_moe` 伴随文件）
- 验证样本：`output/ckpt/sample/` · 推理结果：`output/tests/`

### 7.4 蒙版损失（排除文字气泡）

对漫画/漫画风格数据，把 *对话气泡和文字区域* 从损失中排除，结果会干净得多。蒙版由 SAM3 + MIT 生成（[附录 A](#附录-a-cli-使用方法) 中的 `make mask`），生成的 PNG 是黑白图：**白色 (255) = 参与训练**，**黑色 (0) = 排除**。

若存在 `post_image_dataset/masks/` 会自动使用，否则依次回退到旧版的 `masks/{merged,sam,mit}/`。没有蒙版文件时会直接忽略，因此不做也可以。

## 8. 适配器变体选择指南

> **🌟 推荐**：第一次使用或制作普通的角色/风格 LoRA，请从 **`tlora`（OrthoLoRA + T-LoRA）** 开始。

| 变体 | GUI 变体名 | 何时使用 |
|---|---|---|
| **OrthoLoRA + T-LoRA** ⭐ | `tlora` | **推荐**。基于 SVD 的正交旋转 (OrthoLoRA) + 按时间步的秩掩码 (T-LoRA) 叠加。产出 `anima_tlora_ortho.safetensors` |
| **普通 LoRA** | `lora` | 最简单的基线，用于对比实验 |
| **HydraLoRA** | `hydralora` | MoE 多头路由，把多种概念放进一个适配器 |
| **ChimeraHydra** *(实验性)* | `chimera_hydra` | 内容/频率双池 MoE — 研究用途 |

显存 8~12 GB 的环境不要换变体，而是在 **Hardware 下拉框中选择 Low VRAM**（CLI 为 `PRESET=low_vram`）。可用变体的最新列表见 `configs/gui-methods/` 文件夹。

> **兼容性备注**
> - HydraLoRA 等适配器变体需要 `cache_llm_adapter_outputs = true`（默认已开启）。
> - `tlora` 可以用 `make merge` 烘焙进基础 DiT，做成独立的 ComfyUI 检查点。

各变体的详细选项请参阅 [`docs/guidelines/training.md`](training.md) 以及 `docs/methods/` 下的单独文档。

## 9. 推理

想用刚训练好的适配器出图，点击 GUI 的 **Test** 按钮即可 — 它会自动从 `output/ckpt/` 选取最新的检查点进行推理，并把结果保存到 `output/tests/`。批量生成和精细的参数控制则更适合用 CLI（[附录 A](#附录-a-cli-使用方法)）。

常用选项：

| 选项 | 说明 |
|---|---|
| `--lora_weight` | 训练好的适配器路径（可同时指定多个） |
| `--lora_multiplier` | 适配器强度 (0.0~1.5) |
| `--image_size H W` | 输出分辨率（例如 `1024 1024`、`1024 1536`） |
| `--infer_steps` | 去噪步数（通常 20~50） |
| `--guidance_scale` | CFG 强度（推荐 3.0~5.0） |
| `--sampler` | `er_sde`、`euler`、`dpm++` 等 |
| `--seed` | 复现用随机种子 |
| `--spectrum` | 启用 Spectrum 加速 |
| `--pgraft` | P-GRAFT（去噪后段切断 LoRA）— 后段细节交给基础模型 |

完整选项列表见 [`docs/guidelines/inference.md`](inference.md)。

## 10. 部署到 ComfyUI

ComfyUI 核心原生支持 Anima 基础 DiT（用 `UNETLoader` / `CLIPLoader` 直接加载）。部署方式因适配器类型而异。

### 10.1 经典 LoRA / OrthoLoRA / T-LoRA

把 `output/ckpt/` 中的 `.safetensors` 复制到 `ComfyUI/models/loras/`，即可用 ComfyUI 自带的 LoraLoader 节点使用。

如果想做成更干净的独立检查点，可在 GUI 的 **Merge** 标签页（或 [附录 A](#附录-a-cli-使用方法) 的 `make merge`）中烘焙进基础 DiT。生成的 `*_merged.safetensors` 可在 `UNETLoader` 中作为独立模型加载。

### 10.2 HydraLoRA / Postfix

这些变体不是简单的权重增量，而是包含路由与 token 插入，因此自带的 LoraLoader 无法加载，需要专用节点：

- **Anima Adapter Loader** — <https://github.com/sorryhyun/ComfyUI-Anima_lora-Adapter>（统一处理 LoRA / Hydra / postfix）
- **Spectrum KSampler / Mod Guidance / DCW 节点** — <https://github.com/sorryhyun/ComfyUI-Spectrum-KSampler>

## 11. 更新

在安装目录内运行以下命令，即可拉取 GitHub 发布的最新版本并同步依赖（无需 git）。

```bash
python tasks.py update              # 应用

```

更新不会触碰 `image_dataset/`、`post_image_dataset/`、`output/`、`models/`，用户修改过的配置文件在冲突时会询问。

## 附录 A. CLI 使用方法

GUI 能做的所有事情都可以用 CLI 完成。`make <target>` 与 `python tasks.py <target>` 完全等价；由于一行命令安装不会安装 `make`，**没有 `make` 时使用 `python tasks.py` 即可**（或 `winget install ezwinports.make`）。

> **出现 `ModuleNotFoundError`** 说明是 venv 问题。在命令前加 `uv run`（`uv run python tasks.py lora`），或每个终端先激活一次 venv — 详见 [附录 B](#附录-b-手动安装-uv--git)。

**下载模型**

```bash
hf auth login                # 与 GUI 登录使用同一份令牌缓存
make download-models         # DiT + 文本编码器 + VAE + SAM3 + MIT
make download-anima          # 下载中断时单独重试
make download-sam3           # SAM3 获批后单独运行
make download-mit
```

**预处理**

```bash
make preprocess              # 三个步骤全部执行
make preprocess-resize       # 1) image_dataset/ → post_image_dataset/resized/
make preprocess-vae          # 2) VAE 潜变量缓存
make preprocess-te           # 3) 文本嵌入缓存
make preprocess-pe           # (可选) PE 视觉特征 — 仅 CMMD 验证
make mask                    # 生成蒙版损失所需的蒙版 (SAM3 + MIT)
make mask-clean              # 删除 post_image_dataset/masks/
make autotag --image <path>  # 输出单张图片的预测描述词
```

## 附录 B. 手动安装 (uv · git)

仅当你想自己搭建，而不是用 [§2](#2-安装) 的一行命令时才需要。

```powershell
irm https://astral.sh/uv/install.ps1 | iex   # 1) 安装 uv（在新 shell 中确认 `uv --version`）
```

```bash
git clone https://github.com/sorryhyun/anima_lora.git   # 2) 克隆
cd anima_lora
winget install ezwinports.make                          # 3) (可选) make
uv sync                                                 # 4) 安装依赖
```

`uv sync` 会在 `anima_lora/` 内创建一个 **名为 `.venv/` 的独立 Python 环境**，并把所有依赖装在其中。它不会动系统 Python，因此你不需要自己执行 `pip install`。

**新手最常卡住的地方**：打开新终端直接运行 `python tasks.py ...` 会使用 *系统* Python，从而报 `ModuleNotFoundError`。两种解决方式：

- **加上 `uv run`**（无需激活，任何地方都能用）：`uv run python tasks.py lora`
- **激活 venv**（每个终端窗口一次）：

  ```powershell
  .venv\Scripts\activate        # Windows
  ```
  ```bash
  source .venv/bin/activate     # Linux / macOS / WSL
  ```

  提示符出现 `(anima_lora)` 或 `(.venv)` 前缀即为成功；退出用 `deactivate`。VSCode 用户在命令面板 → *Python: Select Interpreter* 中选一次 `.venv`，集成终端就会自动激活。

## 附录 C. CUDA 手动安装

[§2](#2-安装) 的一行命令会自动处理 CUDA 13.2，已安装则会检测并跳过。本附录 **仅在自动步骤失败时** 需要。

- CUDA 13.x 需要 NVIDIA 驱动 **595 及以上**。如果你已有更新的驱动，请保留它（在 Linux 的 `.run` 安装菜单中取消勾选捆绑驱动）。
- 想自己管理 CUDA，可设置 `$env:ANIMA_SKIP_CUDA='1'`（PowerShell）/ `ANIMA_SKIP_CUDA=1`（shell）跳过自动 CUDA 步骤。

手动安装请从 NVIDIA 存档获取 13.2：<https://developer.nvidia.com/cuda-13-2-0-download-archive>

1. Windows：选择 **Operating System: Windows → Architecture: x86_64 → Version: 11/10 → Installer Type: exe (local)**，运行后选 "Express (Recommended)"。
2. 在 PowerShell 中用 `nvidia-smi` 和 `nvcc --version` 确认（应为 `release 13.2`）。
3. 若找不到 `nvcc`，把下面两条加入系统 `Path`，重启后再确认：

   ```
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\bin
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\libnvvp
   ```

## 附录 D. 其他设置

### `num_repeats`（摘要：**不要调整**）

`configs/base.toml` 的 `[[datasets.subsets]]` 中的一个 kohya-ss 风格选项，指定一个 epoch 内每张图片重复使用多少次。其他训练器的指南里经常出现，但是 —

- **在本指南的工作流中请保持为 `1`。** 把所有图片放在一个文件夹的常见用法下，调大它只会 *让一个 epoch 变长*，效果与增加 `max_train_epochs` 相同。本项目的所有预设与方法配置都以 `num_repeats = 1` 为前提调优。
- **只有在** 一次训练包含多个子集（文件夹）且各文件夹图片数量差异很大时，作为 *平衡工具* 才有意义（例如角色 A 有 1000 张 + B 有 50 张，则只把 B 子集设为 `num_repeats = 20`）。
- 它属于数据集设置，因此不会出现在 GUI 或方法文件中。确有需要时请直接编辑 `configs/base.toml`（或通过 `--dataset_config` 指定的 TOML）。
