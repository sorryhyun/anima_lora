## 2. 설치

PowerShell에 아래 한 줄을 붙여넣으세요. `uv`·CUDA 13.2·Python 3.13·의존성을 모두 자동으로 설치하고, 끝나면 **GUI를 자동으로 열어줍니다.**

```powershell
irm https://raw.githubusercontent.com/sorryhyun/anima_lora/main/install.ps1 | iex
```

- 설치 위치는 `.\anima_lora\` 입니다 (`$env:ANIMA_DIR` 로 변경, `$env:ANIMA_VERSION='v1.4.0'` 으로 버전 고정 가능).
- **재부팅을 요구하면** (CUDA 설치 후 흔합니다) 재부팅한 뒤 같은 명령을 다시 실행하세요 — 이어서 진행됩니다.
- 나중에 다시 열 때는 바탕화면의 **"Anima LoRA GUI"** 바로가기를 사용합니다.

설치가 끝나면 GUI에서 **§3 → §4 → §5** 순서로 진행하면 됩니다.

> 직접 `git clone` 하고 싶거나 자동 설치가 실패했다면 [부록 B](#부록-b-수동-설치-uv--git) / [부록 C](#부록-c-cuda-수동-설치)를 보세요.

## 3. Hugging Face 로그인과 모델 다운로드

### 3.1 로그인

1. <https://huggingface.co/settings/tokens> 에서 **read** 권한 토큰을 발급합니다.
2. GUI의 **Hugging Face 로그인** 필드에 토큰을 붙여넣습니다.

토큰은 Hugging Face 표준 캐시에 저장되므로 GUI와 CLI가 같은 로그인 정보를 공유합니다.

### 3.2 모델 다운로드

GUI의 **Models** 대화상자에서 버튼 하나로 아래 세 가지를 받습니다.

| 파일 | 경로 |
|---|---|
| Anima DiT (확산 모델 본체) | `models/diffusion_models/anima-base-v1.0.safetensors` |
| Qwen3 0.6B 텍스트 인코더 | `models/text_encoders/qwen_3_06b_base.safetensors` |
| QwenImage VAE | `models/vae/qwen_image_vae.safetensors` |

**SAM3**와 **MIT** 체크포인트도 함께 받습니다. 둘은 선택 기능인 마스크드 로스([§7.4](#74-마스크드-로스-텍스트-버블-제외))에만 쓰입니다.

> **SAM3는 게이티드(gated) 모델입니다.** <https://huggingface.co/facebook/sam3> 에서 **Request access**를 눌러 승인을 받아야 하며(몇 분~며칠 소요), 승인 전에는 403 오류로 실패합니다. 핵심 모델 세 가지는 게이티드가 아니고 다운로드도 SAM3 실패와 무관하게 계속되므로, 승인을 기다리는 동안에도 학습을 시작할 수 있습니다.
>
> 다운로드가 자꾸 끊긴다면 [부록 A](#부록-a-cli-사용법)의 개별 다운로드 타겟으로 나눠 받으세요.

## 4. 데이터셋 준비

*이미지 + 같은 이름의 `.txt` 캡션 사이드카* 구조입니다. 원본은 `image_dataset/` 에 둡니다 (하위 폴더 자유).

```
image_dataset/
├─ 00001.png
├─ 00001.txt
├─ 00002.jpg
├─ 00002.txt
└─ subfolder/
   ├─ 00010.webp
   └─ 00010.txt
```

### 4.1 캡션 작성 팁

태그 순서는 Anima 공식 가이드라인대로 항상 `[meta] [character] [series] [artist] [general]` 입니다.

```
absurdres, safe, 1girl, chitanda eru, hyouka, @channel (caststation), full body, serafuku, She is saying hi.
```

- `absurdres`, `highres`, `masterpiece` 같은 **퀄리티 태그는 쓰지 않거나 최소한으로만** 남기는 편이 결과가 좋습니다. (추후 정식 배포될 mod guidance를 쓰면 아예 필요 없습니다.)
- **손으로 쓰기 싫다면** GUI **Dataset** 탭에서 이미지를 고르고 **Autotag**를 누르면 내장 **Anima Tagger**가 올바른 순서로 캡션을 채워줍니다([§6.3](#63-dataset-탭-autotag--grouping)). 다만 결과를 그대로 쓰지 말고 — 특히 캐릭터/시리즈/아티스트 이름은 학습 전에 검토하세요.

## 5. 전처리

학습 속도와 VRAM을 위해 **리사이즈 → VAE 잠재 캐싱 → 텍스트 임베딩 캐싱**을 미리 수행합니다. GUI의 **Preprocess** 탭에서 버튼 하나로 세 단계를 모두 실행합니다.

| 단계 | 하는 일 | 결과물 |
|---|---|---|
| 리사이즈 | VAE 정렬에 맞춰 크기 조정, 이미지별 고정 토큰 버킷 배정, 너무 작은 이미지(기본 0.5MP 미만) 제외 | `post_image_dataset/resized/` |
| VAE 잠재 캐싱 | VAE를 한 번만 돌려 저장 → 학습 중 VAE를 GPU에 올리지 않음 | `post_image_dataset/lora/{stem}_{WxH}_anima.npz` |
| 텍스트 임베딩 캐싱 | Qwen3 0.6B + LLM 어댑터 출력 사전 계산 (캡션 셔플 변형 포함) | `post_image_dataset/lora/{stem}_anima_te.safetensors` |

PE 비전 피처 캐싱(`{stem}_anima_pe.safetensors`)은 CMMD 검증에만 필요한 선택 단계입니다.

> **⚠️ 캐시는 재사용되며 절대 자동 삭제되지 않습니다.**
> 전처리를 다시 실행해도 기존 `.npz` / `_te.safetensors` / `_pe.safetensors` 는 덮어쓰지도 지우지도 않고 **누락된 항목만** 새로 만듭니다. 그래서 재실행이 빠르고 도중에 끊겨도 안전합니다.
>
> - **이미지를 추가**했다면 → 그냥 다시 실행하면 됩니다.
> - **캡션을 수정**했거나 토크나이저/리사이즈 옵션을 바꿨다면 → 단순 재실행으로는 반영되지 않습니다. 캐시 폴더(`post_image_dataset/lora/`)를 직접 지운 뒤 다시 실행하세요.

## 6. GUI 사용법

설정 편집, 데이터셋 탐색, 전처리, 학습 실행/모니터링, LoRA 병합을 한 화면에서 처리합니다.

- **학습 설정 (Training Config)**: 변형 드롭다운(권장 `tlora`)과 **Hardware** 드롭다운(Default 16GB+ / Low VRAM 8GB)을 고르고, 학습 키를 수정한 뒤 그대로 학습을 시작합니다. 데이터 범위(`sample_ratio`, `artists_shard`)는 기본(Basic) 섹션의 일반 입력 필드입니다.
- **전처리 (Preprocess)**: 리사이즈 + VAE + 텍스트 임베딩 캐싱을 한 번에.
- **데이터셋 (Dataset)**: 이미지/캡션 미리보기와 수정, Autotag, Grouping ([§6.3](#63-dataset-탭-autotag--grouping)).
- **병합 (Merge)**: 학습된 LoRA를 베이스 DiT에 베이크해 ComfyUI 단독 체크포인트로 저장 (기본 LoRA / OrthoLoRA / T-LoRA만 지원).

GUI는 `configs/gui-methods/<variant>.toml`(변형별 단일 파일)을 읽고 내부적으로 `train.py`를 호출하므로, 같은 설정을 CLI에서도 그대로 재현할 수 있습니다([부록 A](#부록-a-cli-사용법)).

### 6.1 폼 편집과 저장 동작

학습/전처리 서브프로세스는 디스크의 variant TOML을 다시 읽습니다. 따라서 폼만 고치고 저장하지 않으면 반영되지 않는데, GUI가 이를 두 가지로 처리합니다.

- **변경 감지**: 필드나 `+ Extra args` 를 편집하면 `Save` 버튼이 주황색 `Save *` 로 바뀝니다 — *화면과 디스크가 다르다*는 신호입니다.
- **자동 저장**: 저장을 깜빡하고 `Train` / `Preprocess` 를 눌러도 그 시점의 폼 값이 먼저 파일에 기록된 뒤 실행됩니다. 즉 **화면에 보이는 값이 곧 학습에 쓰이는 값**입니다. (`Test`는 마지막 체크포인트로 추론하므로 자동 저장 대상이 아닙니다.)

> 편집을 되돌리고 싶으면 variant를 다른 것으로 바꿨다가 돌아오세요 — 디스크에서 다시 로드되며 편집이 폐기됩니다.

### 6.2 학습 중단과 GUI 닫기

학습은 GUI 창 안이 아니라, `train.py` 를 분리된 프로세스로 돌리는 백그라운드 **학습 데몬**에서 진행됩니다.

- **`Stop` 버튼은 현재 작업만 중단**합니다. 데몬은 계속 떠 있으면서 큐의 다음 작업으로 넘어갑니다.
- **GUI를 닫아도 학습은 계속됩니다.** 다시 열면 진행 중인 작업에 자동으로 재연결되고(`Re-attached to running job …`), 진행 바와 로그가 실시간으로 이어집니다. 밤새 돌리는 긴 학습에 유용합니다.
- 예외로 **`Test` 와 `Preprocess` 는 창 안의 서브프로세스**라 GUI를 닫으면 취소됩니다.
- 학습을 완전히 끄고 GPU까지 풀려면 CLI의 `make daemon-terminate` 가 필요합니다 ([부록 A](#부록-a-cli-사용법)).

### 6.3 Dataset 탭: Autotag & Grouping

**Autotag — 캡션 자동 생성.** 이미지를 고르고 **Autotag**를 누르면 **Anima Tagger**가 `[meta] [character] [series] [artist] [general]` 순서로 태그를 예측해 캡션 박스를 채웁니다. 첫 클릭 때만 모델을 내려받느라 시간이 걸리고, 이후에는 모델이 백그라운드에 남아 거의 즉시 처리됩니다. 다른 GPU 작업을 시작하면 태거는 알아서 GPU 메모리를 반납합니다.

**Grouping — 유사 이미지 클러스터링.** **Group**을 누르면 거의 동일하거나 같은 장면/캐릭터인 이미지들을 묶어 목록에 **초록색 그룹 헤더**로 표시합니다. 중복 제거나 개념별 비중 조절에 씁니다.

- 파일 이름·캡션이 아니라 *시각적 내용*으로 비교하며, **최상위 폴더 단위**(아티스트/캐릭터 버킷)로 계산되므로 다른 폴더끼리 합쳐지지 않습니다.
- 캐시된 특징을 재사용하므로 이미지를 추가한 뒤 언제든 다시 눌러도 부담이 없습니다.

> 두 기능 모두 **원본** `image_dataset/` 에서 동작하며 전처리 캐시에 영향을 주지 않습니다 — 전처리 *전에* 실행해 캡션을 정리하세요.

## 7. 학습

설정 병합 순서는 `configs/base.toml → configs/presets.toml[<preset>] → configs/methods/<method>.toml → CLI args` 이며, **메소드 설정이 프리셋을 덮어씁니다.**

가장 추천하는 출발점은 **OrthoLoRA + T-LoRA (`tlora` 변형)** 입니다 — 안정성·디테일·스타일 보존의 균형이 가장 좋고, 보통의 캐릭터/스타일 LoRA에 그대로 쓸 수 있습니다. GUI에서는 변형 드롭다운 `tlora` + Hardware 드롭다운만 고르면 됩니다.

### 7.1 자주 만지는 설정값 (LoRA 기준 기본값)

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| `network_dim` | `32` | LoRA 랭크. 클수록 표현력↑, 파라미터↑ |
| `network_alpha` | `32` | LoRA 스케일 (보통 `network_dim`과 같은 값) |
| `learning_rate` | `2e-5` | 학습률. Hydra는 더 낮춰도 됨 |
| `max_train_epochs` | `4` | 데이터셋이 작을수록 에폭↑ |
| `save_every_n_epochs` | `2` (gui-methods) / `4` (methods) | 어댑터 가중치 누적 저장 주기 |
| `checkpointing_epochs` | `2` (gui-methods) / `4` (methods) | 재개용 상태 저장 주기 (단일 파일 덮어쓰기) |
| `caption_dropout_rate` | `0.1` | 캡션 일부를 빈 문자열로 대체 (CFG에 도움) |
| `use_shuffled_caption_variants` | `true` | 캡션 콤마 셔플 변형 사용 |

변형 토글(`use_ortho`, `use_timestep_mask`, `use_moe_style`, `router_source` 등)은 변형별 파일에 이미 세팅되어 있습니다. 추천 `tlora` 는 `use_ortho = true` + `use_timestep_mask = true` 조합입니다.

### 7.2 자동 재개 (checkpointing_epochs)

학습이 끊겨도 **마지막 저장 지점부터 자동으로 이어서** 재개합니다. 정전·OOM·실수로 창 닫기에 대비되며 기본으로 켜져 있습니다. 다시 `Train`을 누르기만 하면 되고, 로그에 `auto-resuming from checkpoint at step N` 이 보이면 정상 재개된 것입니다.

`save_every_n_epochs` 와는 역할이 다릅니다.

| 키 | 저장 대상 | 누적? | 용도 |
|---|---|---|---|
| `save_every_n_epochs` | 어댑터 가중치 (`anima_lora-000004.safetensors` 등) | **누적** (`save_last_n_epochs`로 제한 가능) | 중간 결과 추론, 과적합 시점 비교 |
| `checkpointing_epochs` | 재개용 풀 상태 (옵티마이저 / 스케줄러 / RNG / 가중치) | **단일 파일 덮어씀** (디스크가 부풀지 않음) | 중단 시 이어 학습 |

- 학습이 정상적으로 끝나면 재개용 임시 파일은 자동 삭제되고 최종 결과만 남습니다.
- **데이터셋이나 핵심 설정(랭크·LR·에폭 수 등)을 바꿨다면** 이전 상태로 이어가는 것은 위험합니다. `output/ckpt/<output_name>-checkpoint-state/` 폴더를 수동으로 지운 뒤 새로 시작하세요.

### 7.3 출력물

- 학습된 가중치: `output/ckpt/<output_name>.safetensors` (변형마다 `anima`, `anima_tlora_ortho`, `anima_hydra`, `anima_postfix` 등으로 자동 분기)
- 중간 체크포인트: `output/ckpt/` (`.snapshot.toml` 사이드카 + Hydra의 경우 `_moe` 동반 파일)
- 검증 샘플: `output/ckpt/sample/` · 추론 결과: `output/tests/`

### 7.4 마스크드 로스 (텍스트 버블 제외)

만화/만화풍 데이터에서 *말풍선이나 텍스트 영역*을 손실에서 제외하면 결과가 훨씬 깨끗해집니다. 마스크 생성은 SAM3 + MIT로 수행하며([부록 A](#부록-a-cli-사용법)의 `make mask`), 결과 PNG는 흑백입니다 — **흰색(255) = 학습 대상**, **검정(0) = 제외**.

`post_image_dataset/masks/` 가 있으면 자동으로 사용하고, 없으면 레거시 `masks/{merged,sam,mit}/` 를 순서대로 fallback합니다. 마스크가 아예 없으면 무시되므로 만들지 않아도 됩니다.

## 10. ComfyUI로 배포

ComfyUI 코어는 Anima 베이스 DiT를 기본 지원합니다 (`UNETLoader` / `CLIPLoader`로 그대로 로드). 어댑터 종류에 따라 배포 방식이 다릅니다.

### 10.1 클래식 LoRA / OrthoLoRA / T-LoRA

`output/ckpt/` 의 `.safetensors` 를 `ComfyUI/models/loras/` 에 복사하면 기본 LoraLoader 노드로 바로 쓸 수 있습니다.

단독 체크포인트로 만들고 싶다면 GUI의 **Merge** 탭(또는 [부록 A](#부록-a-cli-사용법)의 `make merge`)에서 베이스 DiT에 베이크하세요. 결과 `*_merged.safetensors` 는 `UNETLoader` 에서 단독 모델로 로드됩니다.

### 10.2 HydraLoRA / Postfix

단순 weight delta가 아니라 라우팅·토큰 삽입이 들어가므로 기본 LoraLoader로는 로드할 수 없고, 전용 노드가 필요합니다.

- **Anima Adapter Loader** — <https://github.com/sorryhyun/ComfyUI-Anima_lora-Adapter> (LoRA / Hydra / postfix 통합)
- **Spectrum KSampler / Mod Guidance / DCW 노드** — <https://github.com/sorryhyun/ComfyUI-Spectrum-KSampler>

## 부록 A. CLI 사용법

GUI로 하는 모든 작업은 CLI로도 가능합니다. `make <target>` 과 `python tasks.py <target>` 은 완전히 동일하며, 한 줄 설치는 `make` 를 깔지 않으므로 **`make` 가 없다면 `python tasks.py` 를 쓰면 됩니다** (또는 `winget install ezwinports.make`).

> **`ModuleNotFoundError` 가 난다면** venv 문제입니다. 명령 앞에 `uv run` 을 붙이거나(`uv run python tasks.py lora`), 터미널마다 한 번 venv를 활성화하세요 — 자세한 내용은 [부록 B](#부록-b-수동-설치-uv--git).

**모델 다운로드**

```bash
hf auth login                # GUI 로그인과 같은 토큰 캐시를 사용
make download-models         # DiT + 텍스트 인코더 + VAE + SAM3 + MIT
make download-anima          # 다운로드가 끊길 때 개별 재시도
make download-sam3           # SAM3 승인을 받은 뒤 따로 실행
make download-mit
```

**전처리**

```bash
make preprocess              # 세 단계 모두
make preprocess-resize       # 1) image_dataset/ → post_image_dataset/resized/
make preprocess-vae          # 2) VAE 잠재변수 캐싱
make preprocess-te           # 3) 텍스트 임베딩 캐싱
make preprocess-pe           # (선택) PE 비전 피처 — CMMD 검증 전용
make mask                    # 마스크드 로스용 마스크 생성 (SAM3 + MIT)
make mask-clean              # post_image_dataset/masks/ 삭제
make autotag --image <path>  # 이미지 한 장의 예측 캡션 출력
make curate-group            # 유사 이미지 그룹화 → post_image_dataset/groups/groups.json
```

**학습**

```bash
make lora-gui GUI_PRESETS=tlora                  # 권장 조합 (GUI와 동일한 변형별 파일)
PRESET=low_vram make lora-gui GUI_PRESETS=tlora  # VRAM 8~12GB
make lora-gui GUI_PRESETS=lora                   # 평범한 LoRA
make lora-gui GUI_PRESETS=hydralora              # MoE 다중 헤드
make exp-chimera                                 # ChimeraHydra (실험적)

make lora                                        # configs/methods/lora.toml 토글 블록 방식
PRESET=half make lora                            # 데이터셋 절반만 사용해 빠른 실험

make lora -- --network_dim 32 --max_train_epochs 24   # 임의 키 오버라이드
make daemon-terminate                            # 진행 중 작업 종료 + 데몬 정지 (GPU 반환)
```

**추론**

```bash
make test                        # 일반 LoRA / OrthoLoRA / T-LoRA
make test SPECTRUM=1             # Spectrum 가속
make test MOD=1                  # Modulation guidance (SPECTRUM=1과 조합 가능)
make test NOLORA=1               # 베이스 DiT 단독
make test-hydra                  # HydraLoRA (router-live)
make test-merge                  # 베이크된 단독 DiT로 추론
```

수동 추론:

```bash
python inference.py \
    --dit models/diffusion_models/anima-base-v1.0.safetensors \
```

## 부록 B. 수동 설치 (uv · git)

한 줄 설치([§2](#2-설치)) 대신 직접 받고 싶을 때만 필요합니다.

```powershell
irm https://astral.sh/uv/install.ps1 | iex   # 1) uv 설치 (새 셸에서 `uv --version` 확인)
```

```bash
git clone https://github.com/sorryhyun/anima_lora.git   # 2) 클론
cd anima_lora
winget install ezwinports.make                          # 3) (선택) make
uv sync                                                 # 4) 의존성 설치
```

`uv sync` 는 `anima_lora/` 안에 **`.venv/` 라는 독립 파이썬 환경**을 만들고 그 안에 모든 의존성을 넣습니다. 시스템 파이썬은 건드리지 않으므로 별도로 `pip install` 할 필요가 없습니다.

**초보자가 가장 많이 막히는 지점**: 새 터미널을 열고 그냥 `python tasks.py ...` 를 실행하면 *시스템* 파이썬이 쓰여 `ModuleNotFoundError` 가 납니다. 둘 중 하나로 해결하세요.

- **`uv run` 붙이기** (활성화 불필요, 어디서나 동작): `uv run python tasks.py lora`
- **venv 활성화** (터미널 창마다 한 번씩):

  ```powershell
  .venv\Scripts\activate        # Windows
  ```
  ```bash
  source .venv/bin/activate     # Linux / macOS / WSL
  ```

  프롬프트에 `(anima_lora)` 또는 `(.venv)` 가 보이면 성공입니다. 끝내려면 `deactivate`. VSCode는 명령 팔레트 → *Python: Select Interpreter* 로 `.venv` 를 한 번 지정해두면 통합 터미널이 자동 활성화합니다.

## 부록 C. CUDA 수동 설치

[§2](#2-설치)의 한 줄 설치가 CUDA 13.2를 자동으로 처리하며, 이미 설치돼 있으면 감지하고 건너뜁니다. 이 부록은 **자동 단계가 실패했을 때만** 필요합니다.

- CUDA 13.x는 NVIDIA 드라이버 **595 이상**을 요구합니다. 이미 더 최신 드라이버가 있다면 그대로 두세요 (Linux `.run` 설치 메뉴에서 번들 드라이버 선택 해제).
- CUDA를 직접 관리하고 싶다면 `$env:ANIMA_SKIP_CUDA='1'` (PowerShell) / `ANIMA_SKIP_CUDA=1` (셸) 로 자동 CUDA 단계를 건너뛸 수 있습니다.

수동 설치는 NVIDIA 아카이브에서 13.2를 받습니다: <https://developer.nvidia.com/cuda-13-2-0-download-archive>

1. Windows: **Operating System: Windows → Architecture: x86_64 → Version: 11/10 → Installer Type: exe (local)** 을 받아 실행하고 "Express (Recommended)" 선택.
2. PowerShell에서 `nvidia-smi` 와 `nvcc --version` 으로 확인 (`release 13.2`).
3. `nvcc` 를 못 찾으면 시스템 `Path` 에 아래를 추가한 뒤 재부팅하고 다시 확인하세요.

   ```
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\bin
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\libnvvp
   ```

## 부록 D. 그 밖의 설정

### `num_repeats` (요약: **만지지 않습니다**)

`configs/base.toml` 의 `[[datasets.subsets]]` 에 있는 kohya-ss 스타일 옵션으로, 한 에폭 동안 각 이미지를 몇 번 반복할지 지정합니다. 다른 트레이너 가이드에서 자주 보이지만 —

- **이 가이드의 워크플로우에서는 `1` 로 두세요.** 모든 이미지를 한 폴더에 모아 쓰는 일반적인 패턴에서는 값을 올려도 *한 에폭이 길어질 뿐*, 효과는 `max_train_epochs` 를 늘리는 것과 같습니다. 본 프로젝트의 모든 프리셋·메소드는 `num_repeats = 1` 전제로 튜닝돼 있습니다.
- **의미가 있는 경우**는 서브셋(폴더)이 여러 개이고 폴더별 이미지 수가 크게 다를 때의 *밸런싱* 뿐입니다 (예: 캐릭터 A 1000장 + B 50장이면 B 서브셋만 `num_repeats = 20`).
- 데이터셋 설정이라 GUI·메소드 파일에는 노출되지 않습니다. 정말 필요하면 `configs/base.toml` (또는 `--dataset_config` 로 지정한 TOML)을 직접 편집하세요.
