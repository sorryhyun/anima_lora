# 安装

本仓库所有产品线（Anima、MOSS-Image）共用的安装步骤：系统要求、安装、Hugging Face 登录、更新。安装完成后，下载所用产品线的模型 — Anima：[指南书 §3](../guidelines/指南书.md#3-hugging-face-登录与模型下载)；MOSS-Image：[MOSS 指南书 §2](../guidelines/moss-指南书.md#2-安装)。

---

## 1. 系统要求

| 项目 | 最低 | 推荐 |
|---|---|---|
| GPU | RTX 3060 及以上（20xx 系列及以下无法使用） | 显存 16 GB 以上 |
| 系统内存 | 16 GB | 32 GB 以上 |
| 硬盘 | 60 GB 可用空间 | 200 GB 以上（缓存 + 输出累积） |
| 操作系统 | Windows 11 / Ubuntu 22.04+ | Ubuntu 24.04 |
| Python | 必须为 3.13 | - |
| NVIDIA 驱动 | 595 及以上（CUDA 13.x 要求） | - |

MOSS-Image 在 16 GB 显卡上测得；显存方案见 [MOSS 指南书 §4.2](../guidelines/moss-指南书.md#42-显存方案16-gb)。

---

## 2. 安装

根据系统，把对应的一行粘贴到 PowerShell（Windows）或终端（Linux / macOS）中。它会自动安装 `uv`、CUDA 13.2、Python 3.13 和全部依赖，完成后 自动打开 GUI。

```powershell
# Windows (PowerShell)
irm https://github.com/sorryhyun/anima_lora/releases/latest/download/install.ps1 | iex
```
```bash
# Linux / macOS
curl -LsSf https://github.com/sorryhyun/anima_lora/releases/latest/download/install.sh | sh
```

- 安装位置为 `.\anima_lora\`（可用 `$env:ANIMA_DIR` 修改，用 `$env:ANIMA_VERSION='v2.0.0'` 固定版本）。
- 如果提示需要重启（CUDA 安装后很常见），重启后再次运行同一条命令 — 会从中断处继续。
- 之后请通过桌面的 "Anima LoRA GUI" 快捷方式启动。

> 如果想自己 `git clone`，或自动安装失败，请参阅 [附录 A](#附录-a-手动安装-uv--git) / [附录 B](#附录-b-cuda-手动安装)。

> Windows 上的 AMD Radeon：同一条命令会选用 ROCm，详见 [rocm.md](rocm.md)（英文）。

---

## 3. Hugging Face 登录

1. 在 <https://huggingface.co/settings/tokens> 创建一个 read 权限的令牌。
2. 将令牌粘贴到 GUI 的 Hugging Face 登录 输入框。

令牌保存在 Hugging Face 标准缓存中，因此 GUI 与 CLI 共用同一份登录信息。

---

## 4. 更新

在安装目录内运行以下命令，即可拉取 GitHub 发布的最新版本并同步依赖（无需 git）。

```bash
python tasks.py update              # 应用
python tasks.py update -- --dry-run # 预览哪些文件会变化
```

更新不会触碰 `image_dataset/`、`post_image_dataset/`、`output/`、`models/`，用户修改过的配置文件在冲突时会询问。

---

## 5. RTX 50 系列：打过补丁的 FlashAttention（可选）

在 RTX 50 系列显卡上，我们的 FlashAttention 构建（[sorryhyun/flash-attention-fp16](https://github.com/sorryhyun/flash-attention-fp16)）可让 MOSS-Image、Anima 的训练步快约 5%，生成速度基本不变。提供 Windows 与 Linux x86_64 的 wheel。在安装目录内运行：

```bash
uv sync --no-default-groups --group fa2-sm120
```

- 不带参数的 `uv sync` 或 `python tasks.py update` 会换回标准 wheel。若要在更新后保留，请设置 `ANIMA_TORCH=2.14-sm120` 后更新一次（PowerShell：`$env:ANIMA_TORCH='2.14-sm120'; python tasks.py update`）。
- 只包含 sm_120 内核，其他显卡请继续使用标准 wheel。
- 同一 venv 中运行的 ComfyUI 也会使用此构建。

详情：[fa2_sm120.md](../moss/optimization/fa2_sm120.md)。

## 附录 A. 手动安装 (uv · git)

仅当你想自己搭建，而不是用 [§2](#2-安装) 的一行命令时才需要。

```powershell
irm https://astral.sh/uv/install.ps1 | iex   # 1) 安装 uv（在新 shell 中确认 `uv --version`）
```

```bash
git clone https://github.com/sorryhyun/anima_lora.git   # 2) 克隆
cd anima_lora
winget install ezwinports.make                          # 3) (可选) make
uv sync                                                 # 4) 安装依赖
```

`uv sync` 会把所有依赖安装到 `anima_lora/` 内的 `.venv/` 中，不需要你自己执行 `pip install`。

打开新终端直接运行 `python tasks.py ...` 会使用 *系统* Python，从而报 `ModuleNotFoundError`。两种解决方式：

- 加上 `uv run`（无需激活，任何地方都能用）：`uv run python tasks.py lora`
- 激活 venv（每个终端窗口一次）：

  ```powershell
  .venv\Scripts\activate        # Windows
  ```
  ```bash
  source .venv/bin/activate     # Linux / macOS / WSL
  ```

  提示符出现 `(anima_lora)` 或 `(.venv)` 前缀即为成功；退出用 `deactivate`。VSCode 用户在命令面板 → Python: Select Interpreter 中选一次 `.venv`，集成终端就会自动激活。

## 附录 B. CUDA 手动安装

[§2](#2-安装) 的一行命令会自动处理 CUDA 13.2，已安装则会检测并跳过。本附录 仅在自动步骤失败时 需要。

- CUDA 13.x 需要 NVIDIA 驱动 595 及以上。如果你已有更新的驱动，请保留它（在 Linux 的 `.run` 安装菜单中取消勾选捆绑驱动）。
- 想自己管理 CUDA，可设置 `$env:ANIMA_SKIP_CUDA='1'`（PowerShell）/ `ANIMA_SKIP_CUDA=1`（shell）跳过自动 CUDA 步骤。

手动安装请从 NVIDIA 存档获取 13.2：<https://developer.nvidia.com/cuda-13-2-0-download-archive>

1. Windows：选择 Operating System: Windows → Architecture: x86_64 → Version: 11/10 → Installer Type: exe (local)，运行后选 "Express (Recommended)"。
2. 在 PowerShell 中用 `nvidia-smi` 和 `nvcc --version` 确认（应为 `release 13.2`）。
3. 若找不到 `nvcc`，把下面两条加入系统 `Path`，重启后再确认：

   ```
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\bin
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\libnvvp
   ```
