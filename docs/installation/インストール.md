# インストール

このリポジトリのすべてのライン（Anima、MOSS-Image）で共通のセットアップです：要件、インストール、Hugging Face サインイン、アップデート。インストール後は使うラインのモデルをダウンロードします — Anima：[ガイドブック §3](../guidelines/ガイドブック.md#3-hugging-face-サインインとモデルのダウンロード)、MOSS-Image：[MOSS ガイドブック §2](../guidelines/moss-ガイドブック.md#2-セットアップ)。

---

## 1. システム要件

| 項目 | 最小 | 推奨 |
|---|---|---|
| GPU | RTX 3060 以上（20xx シリーズ以下は使用不可） | VRAM 16 GB 以上 |
| システム RAM | 16 GB | 32 GB 以上 |
| ディスク | 60 GB の空き | 200 GB 以上（キャッシュ + 出力の蓄積用） |
| OS | Windows 11 / Ubuntu 22.04+ | Ubuntu 24.04 |
| Python | 必ず 3.13 | - |
| NVIDIA ドライバ | 595 以上（CUDA 13.x の要件） | - |

MOSS-Image は 16 GB のカードで計測しています。メモリ構成は [MOSS ガイドブック §4.2](../guidelines/moss-ガイドブック.md#42-メモリ構成16-gb) にあります。

---

## 2. インストール

OS に合わせた 1 行を PowerShell（Windows）またはターミナル（Linux / macOS）に貼り付けてください。`uv`・CUDA 13.2・Python 3.13・依存関係をすべて自動でインストールし、完了すると GUI を自動的に開きます。

```powershell
# Windows (PowerShell)
irm https://github.com/sorryhyun/anima_lora/releases/latest/download/install.ps1 | iex
```
```bash
# Linux / macOS
curl -LsSf https://github.com/sorryhyun/anima_lora/releases/latest/download/install.sh | sh
```

- インストール先は `.\anima_lora\` です（`$env:ANIMA_DIR` で変更、`$env:ANIMA_VERSION='v2.0.0'` でバージョン固定が可能）。
- 再起動を求められたら（CUDA インストール後によくあります）、再起動してから同じコマンドを再実行してください — 続きから進みます。
- 次回以降はデスクトップの 「Anima LoRA GUI」 ショートカットから起動します。

> 自分で `git clone` したい場合や自動インストールが失敗した場合は [付録 A](#付録-a-手動インストール-uv--git) / [付録 B](#付録-b-cuda-の手動インストール) を参照してください。

> Windows の AMD Radeon：同じワンライナーが ROCm を選びます。詳細は [rocm.md](rocm.md)（英語）。

---

## 3. Hugging Face サインイン

1. <https://huggingface.co/settings/tokens> で read 権限のトークンを発行します。
2. GUI の Hugging Face サインイン 欄にトークンを貼り付けます。

トークンは Hugging Face 標準のキャッシュに保存されるため、GUI と CLI が同じ認証情報を共有します。

---

## 4. アップデート

インストールフォルダ内で以下を実行すると、GitHub リリースの最新版を取得して適用し、依存関係まで同期します（git 不要）。

```bash
python tasks.py update              # 適用
python tasks.py update -- --dry-run # どのファイルが変わるかプレビュー
```

`image_dataset/`、`post_image_dataset/`、`output/`、`models/` には触れず、ユーザーが変更した設定ファイルは競合時に確認します。

## 5. RTX 50 シリーズ: パッチ済み FlashAttention（任意）

RTX 50 シリーズのカードでは、当リポジトリの FlashAttention ビルド（[sorryhyun/flash-attention-fp16](https://github.com/sorryhyun/flash-attention-fp16)）で MOSS-Image・Anima の学習ステップが約 5% 速くなります。生成はほとんど変わりません。Windows と Linux x86_64 用のホイールがあります。インストールフォルダで実行してください:

```bash
uv sync --no-default-groups --group fa2-sm120
```

- フラグなしの `uv sync` や `python tasks.py update` は標準のホイールに戻します。アップデート後も維持するには、`ANIMA_TORCH=2.14-sm120` を設定して一度アップデートしてください（PowerShell: `$env:ANIMA_TORCH='2.14-sm120'; python tasks.py update`）。
- sm_120 のカーネルしか含まないため、他のカードでは標準のホイールを使ってください。
- 同じ venv で動く ComfyUI もこのビルドを使います。

詳細: [fa2_sm120.md](../moss/optimization/fa2_sm120.md)。

## 付録 A. 手動インストール (uv · git)

ワンラインインストール（[§2](#2-インストール)）の代わりに自分で構築したい場合にのみ必要です。

```powershell
irm https://astral.sh/uv/install.ps1 | iex   # 1) uv のインストール（新しいシェルで `uv --version` を確認）
```

```bash
git clone https://github.com/sorryhyun/anima_lora.git   # 2) クローン
cd anima_lora
winget install ezwinports.make                          # 3) (オプション) make
uv sync                                                 # 4) 依存関係のインストール
```

`uv sync` は `anima_lora/` の中の `.venv/` にすべての依存関係をインストールします。`pip install` を別途行う必要はありません。

新しいターミナルで `python tasks.py ...` を実行すると *システム* の Python が使われ、`ModuleNotFoundError` になります。次のどちらかで解決してください。

- `uv run` を付ける（有効化不要、どこでも動作）: `uv run python tasks.py lora`
- venv を有効化する（ターミナルウィンドウごとに 1 回）:

  ```powershell
  .venv\Scripts\activate        # Windows
  ```
  ```bash
  source .venv/bin/activate     # Linux / macOS / WSL
  ```

  プロンプトに `(anima_lora)` または `(.venv)` が表示されれば成功です。終了するには `deactivate`。VSCode ではコマンドパレット → Python: Select Interpreter で `.venv` を一度指定しておけば、統合ターミナルが自動的に有効化します。

## 付録 B. CUDA の手動インストール

[§2](#2-インストール) のワンラインインストールが CUDA 13.2 を自動的に処理し、既にインストール済みなら検出してスキップします。この付録は 自動ステップが失敗した場合にのみ 必要です。

- CUDA 13.x は NVIDIA ドライバ 595 以上 を要求します。既により新しいドライバがある場合はそのままにしてください（Linux の `.run` インストールメニューでバンドルドライバの選択を解除）。
- CUDA を自分で管理したい場合は `$env:ANIMA_SKIP_CUDA='1'`（PowerShell）/ `ANIMA_SKIP_CUDA=1`（シェル）で自動 CUDA ステップをスキップできます。

手動インストールは NVIDIA アーカイブから 13.2 を取得します: <https://developer.nvidia.com/cuda-13-2-0-download-archive>

1. Windows: Operating System: Windows → Architecture: x86_64 → Version: 11/10 → Installer Type: exe (local) を選んで実行し、「Express (Recommended)」を選択します。
2. PowerShell で `nvidia-smi` と `nvcc --version` を確認（`release 13.2`）。
3. `nvcc` が見つからない場合は、システムの `Path` に以下を追加して再起動し、再度確認してください。

   ```
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\bin
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\libnvvp
   ```
