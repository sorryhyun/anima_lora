# 설치

이 저장소의 모든 라인(Anima, MOSS-Image)이 공유하는 설치 과정입니다: 요구사항, 설치, Hugging Face 로그인, 업데이트. 설치가 끝나면 사용할 라인의 모델을 받습니다 — Anima: [가이드북 §3](../guidelines/가이드북.md#3-hugging-face-로그인과-모델-다운로드), MOSS-Image: [MOSS 가이드북 §2](../guidelines/moss-가이드북.md#2-설치).

---

## 1. 시스템 요구사항

| 항목 | 최소 | 권장 |
|---|---|---|
| GPU | RTX 3060 이상 (2xxx 이하 사용 불가) | VRAM 16 GB 이상 |
| 시스템 RAM | 16 GB | 32 GB 이상 |
| 디스크 | 60 GB 여유 | 200 GB 이상 (캐시 + 출력 누적용) |
| 운영체제 | Windows 11 / Ubuntu 22.04+ | Ubuntu 24.04 |
| Python | 반드시 3.13 | - |
| NVIDIA 드라이버 | 595 이상 (CUDA 13.x 요구사항) | - |

MOSS-Image는 16 GB 카드에서 측정했습니다. 메모리 구성은 [MOSS 가이드북 §4.2](../guidelines/moss-가이드북.md#42-메모리-구성-16-gb)에 있습니다.

## 2. 설치

OS에 맞는 한 줄을 PowerShell(Windows) 또는 터미널(Linux / macOS)에 붙여넣으세요. `uv`·CUDA 13.2·Python 3.13·의존성을 모두 자동으로 설치하고, 끝나면 GUI를 자동으로 열어줍니다.

```powershell
# Windows (PowerShell)
irm https://github.com/sorryhyun/anima_lora/releases/latest/download/install.ps1 | iex
```
```bash
# Linux / macOS
curl -LsSf https://github.com/sorryhyun/anima_lora/releases/latest/download/install.sh | sh
```

- 설치 위치는 `.\anima_lora\` 입니다 (`$env:ANIMA_DIR` 로 변경, `$env:ANIMA_VERSION='v2.0.0'` 으로 버전 고정 가능).
- 재부팅을 요구하면 (CUDA 설치 후 흔합니다) 재부팅한 뒤 같은 명령을 다시 실행하세요 — 이어서 진행됩니다.
- 나중에 다시 열 때는 바탕화면의 "Anima LoRA GUI" 바로가기를 사용합니다.

> 직접 `git clone` 하고 싶거나 자동 설치가 실패했다면 [부록 A](#부록-a-수동-설치-uv--git) / [부록 B](#부록-b-cuda-수동-설치)를 보세요.

> Windows의 AMD Radeon: 같은 한 줄 설치가 ROCm을 선택합니다. 자세한 내용은 [rocm.md](rocm.md) (영문).

## 3. Hugging Face 로그인

1. <https://huggingface.co/settings/tokens> 에서 read 권한 토큰을 발급합니다.
2. GUI의 Hugging Face 로그인 필드에 토큰을 붙여넣습니다.

토큰은 Hugging Face 표준 캐시에 저장되므로 GUI와 CLI가 같은 로그인 정보를 공유합니다.

## 4. 업데이트

폴더 안에서 아래를 실행하면 GitHub 릴리즈의 최신 버전을 받아 적용하고 의존성까지 동기화합니다 (git 불필요).

```bash
python tasks.py update              # 적용
python tasks.py update -- --dry-run # 어떤 파일이 바뀌는지 미리 보기
```

`image_dataset/`, `post_image_dataset/`, `output/`, `models/` 는 건드리지 않으며, 사용자가 수정한 설정 파일은 충돌 시 물어봅니다.

## 5. RTX 50 시리즈: 패치된 FlashAttention (선택)

RTX 50 시리즈 카드에서는 저희 FlashAttention 빌드([sorryhyun/flash-attention-fp16](https://github.com/sorryhyun/flash-attention-fp16))가 MOSS-Image·Anima 학습 스텝을 약 5% 빠르게 합니다. 생성 속도는 거의 그대로입니다. Windows와 Linux x86_64용 휠이 있습니다. 설치 폴더에서 실행하세요:

```bash
uv sync --no-default-groups --group fa2-sm120
```

- 플래그 없는 `uv sync` 나 `python tasks.py update` 는 기본 휠로 되돌립니다. 업데이트 후에도 유지하려면 `ANIMA_TORCH=2.14-sm120` 을 설정한 채로 한 번 업데이트하세요 (PowerShell: `$env:ANIMA_TORCH='2.14-sm120'; python tasks.py update`).
- sm_120 커널만 들어 있으므로, 다른 카드에서는 기본 휠을 쓰세요.
- 같은 venv에서 도는 ComfyUI도 이 빌드를 씁니다.

자세한 내용: [fa2_sm120.md](../moss/optimization/fa2_sm120.md).

## 부록 A. 수동 설치 (uv · git)

한 줄 설치([§2](#2-설치)) 대신 직접 받고 싶을 때만 필요합니다.

```powershell
irm https://astral.sh/uv/install.ps1 | iex   # 1) uv 설치 (새 셸에서 `uv --version` 확인)
```

```bash
git clone https://github.com/sorryhyun/anima_lora.git   # 2) 클론
cd anima_lora
winget install ezwinports.make                          # 3) (선택) make
uv sync                                                 # 4) 의존성 설치
```

`uv sync` 는 `anima_lora/` 안의 `.venv/` 에 모든 의존성을 설치합니다. `pip install` 은 따로 할 필요가 없습니다.

새 터미널에서 `python tasks.py ...` 를 실행하면 *시스템* 파이썬이 쓰여 `ModuleNotFoundError` 가 납니다. 둘 중 하나로 해결하세요.

- `uv run` 붙이기 (활성화 불필요, 어디서나 동작): `uv run python tasks.py lora`
- venv 활성화 (터미널 창마다 한 번씩):

  ```powershell
  .venv\Scripts\activate        # Windows
  ```
  ```bash
  source .venv/bin/activate     # Linux / macOS / WSL
  ```

  프롬프트에 `(anima_lora)` 또는 `(.venv)` 가 보이면 성공입니다. 끝내려면 `deactivate`. VSCode는 명령 팔레트 → Python: Select Interpreter 로 `.venv` 를 한 번 지정해두면 통합 터미널이 자동 활성화합니다.

## 부록 B. CUDA 수동 설치

[§2](#2-설치)의 한 줄 설치가 CUDA 13.2를 자동으로 처리하며, 이미 설치돼 있으면 감지하고 건너뜁니다. 이 부록은 자동 단계가 실패했을 때만 필요합니다.

- CUDA 13.x는 NVIDIA 드라이버 595 이상을 요구합니다. 이미 더 최신 드라이버가 있다면 그대로 두세요 (Linux `.run` 설치 메뉴에서 번들 드라이버 선택 해제).
- CUDA를 직접 관리하고 싶다면 `$env:ANIMA_SKIP_CUDA='1'` (PowerShell) / `ANIMA_SKIP_CUDA=1` (셸) 로 자동 CUDA 단계를 건너뛸 수 있습니다.

수동 설치는 NVIDIA 아카이브에서 13.2를 받습니다: <https://developer.nvidia.com/cuda-13-2-0-download-archive>

1. Windows: Operating System: Windows → Architecture: x86_64 → Version: 11/10 → Installer Type: exe (local) 을 받아 실행하고 "Express (Recommended)" 선택.
2. PowerShell에서 `nvidia-smi` 와 `nvcc --version` 으로 확인 (`release 13.2`).
3. `nvcc` 를 못 찾으면 시스템 `Path` 에 아래를 추가한 뒤 재부팅하고 다시 확인하세요.

   ```
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\bin
   C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.2\libnvvp
   ```
