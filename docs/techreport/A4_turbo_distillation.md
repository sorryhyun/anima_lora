# 부록 4. DP-DMD 공동 루프의 세부와 측정

`04_turbo_distillation.md` §1.2에서 말한 DP-DMD 공동 루프(DM, CDM, fake, GAN을 함께 학습)의 세부 설정과
측정입니다. 공동 루프는 v4_preview까지의 레시피였고, 그 뒤의 레시피는 본문에 있습니다. A4.6은 본문 §2의 warm start에
쓴 delta의 출처입니다.

## A4.1 루프 세부

### 한 iteration의 순서

| # | 단계 | forward | grad |
|---|---|---|---|
| 1 | teacher K-step CFG 앵커 → $v_{\text{target}}$ | teacher × 2K (K 6이면 12) | 없음 |
| 2 | student 롤아웃, 스텝 0 다양성 loss, grad 스텝 g의 x0 예측 | student × (g+1) | 스텝 0 (앵커), 스텝 g |
| 3 | DM 서로게이트 (DMD 또는 MFD) | teacher × 2, fake × 1 (MFD면 K배) | 없음 (신호만) |
| 4 | CDM 항, 따로 backward | student × 1 (grad), teacher × 1 (cond만), fake × 1 | student |
| 5 | GAN generator 항 | teacher × 1 (블록 중간에서 early exit, grad 통과) | student |
| 6 | student loss 합산 → backward → clip → step → EMA | | |
| 7 | fake 업데이트 × (student 스텝당 fake 스텝 수), 매번 disc 1회 | fake × 1 (grad) + teacher × 2 (grad 없음, 절반 깊이) | fake, disc |

### DM 신호

- **x0 정규화.** 켜면 샘플마다 $\tau\Delta_{dm} / \max\big(\operatorname{mean}|\tau v_{\text{real}}|,\
  \text{floor}\big)$로 크기를 정규화하고, 이때 τ가 대부분 상쇄됩니다. 끄면 τ-damping만 남습니다. 레시피는
  정규화를 켜고 floor를 0.05로 둡니다.
- **DM draw 수.** 같은 x0 예측에 (τ, ε_dm)를 여러 번 뽑아 신호를 평균할 수 있습니다. loss가 신호에 선형이라
  backward는 한 번입니다. 2스텝에서 효과가 없어서 레시피는 1입니다(A4.3.3).

### 다양성 앵커의 값

| 항목 | 레시피 값 | 의미 |
|---|---|---|
| 앵커 스텝 K / teacher 앵커 격자 길이 | 6 / 12 | 둘의 비가 앵커가 떨어지는 σ 지점을 정합니다(6/12 = 0.5). 스텝 수는 teacher를 얼마나 촘촘히 적분하는지와 비용만 정합니다 |
| 다양성 가중 λ | 0.1 | 스텝 0 MSE의 가중치입니다. 0이면 앵커 자체를 건너뜁니다(teacher forward 2·K회 절약) |
| 첫 스텝 뒤 detach | on | **필수**입니다. 다양성 항을 즉시 backward하고 스텝 0 그래프를 끊습니다. DMD reverse-KL이 첫 스텝으로 흘러들면 다양성이 다시 줄어듭니다(DP-DMD 논문 Fig. 5) |
| 스텝 0에도 DM | on | grad 스텝을 $U\{0..N-1\}$에서 뽑아 스텝 0도 DM 신호를 받습니다. g = 0이면 다양성 항과 같은 backward에 실립니다. λ 0과 함께 쓰면 MFD 논문의 앵커 없는 루프가 되는데, 이 조합은 250스텝 안에 붕괴했습니다(A4.3.7) |

### transition-aware fake의 A/B

시드, init, 데이터 순서가 같은 런 한 쌍의 500스텝 A/B에서 350–500스텝의 쌍별 차는 fake loss
−0.002 ± 0.003, DM 차 RMS +0.002 ± 0.003이었고, teacher와 fake velocity의
cos는 둘 다 0.978이었습니다. 렌더는 transition-aware 쪽이 더 선명하고 teacher에 가까웠는데,
이것은 런 한 쌍의 비교입니다(A4.3.1). 해가 없어서 레시피에 둡니다.

### GAN 세부

- token head(LADD 방식, 토큰마다 logit)와 pooled head(탭마다 logit 하나)는 파라미터 수가 같습니다. token head는
  글자, 손, 질감 같은 국소 결함을 벌합니다.
- 레시피는 generator 가중 0.03, disc LR 1e-5, disc AdamW betas (0, 0.99), 중간 블록입니다.
- GAN 기울기는 DM 기울기와 원소 단위로 직교합니다(A4.4). 즉 텍스처는 사 오고, 다양성은 사 오지 않습니다.
- 2스텝에서 token disc가 폭주한 적이 있습니다(margin 0.22 → 6.94, spread → 0.99). 4스텝에서는 같은 설정이
  평탄했습니다. 폭주의 서명과 완화법은 A4.5에 있습니다.

## A4.2 레시피를 정한 실험

기준 설정(상수 LR 250 iteration, 동적 격자, 첫 스텝 DM off, CFG를 건 CDM)에서 공동 루프의 최종 레시피까지 네 가지를
바꿨습니다. 순서대로 cosine LR과 1000 iteration, 첫 스텝 DM, static 격자, cond-only CDM입니다. teacher는 처음 세
변경까지 soup teacher의 이전 판이었고, cond-only CDM부터 같은 8개 그룹 soup을 위치 절 캡션으로 다시 학습한
판입니다. 비교에 쓴 probe는 다음과 같습니다.

- **앵커 MSE.** held-out 조건에서 student 첫 스텝의 velocity와 앵커 target 사이의 MSE입니다. 첫 스텝이 teacher의
  구도를 얼마나 따라가는지를 봅니다.
- **teacher 유사도(S cos).** 같은 노이즈에서 student 4스텝 결과와 teacher 결과의 cos입니다(8× average pool 뒤
  채널 평균을 뺀 latent).
- **시드 간 유사도.** 같은 프롬프트의 시드 사이에서 잰 같은 cos의 평균입니다. 낮을수록 다양하고, teacher는
  0.315–0.328입니다.

### cosine LR과 1000 iteration

첫 스텝의 앵커 MSE는 런 길이보다 학습 끝의 LR을 따랐습니다.

| 런 | 앵커 MSE |
|---|---|
| 상수 5e-5, 250 / 500 / 750 / 1000 iteration | 0.165 / 0.143 / 0.155 / 0.140 |
| 같은 런의 마지막 250 iteration만 annealing | 0.123 |
| cosine 500 iteration 두 런 | 0.109 / 0.118 |
| 앵커 draw 4번 / 체크포인트 평균 | 0.147 / 0.156 |

cosine은 상수 LR 런이 쓰는 LR 합의 55 %만 씁니다. 2e-4 peak는 학습하지 않은 것보다 첫 스텝을 못 맞췄습니다(0.277 대
0.171).

### 첫 스텝 DM

앵커 회귀만으로는 지금까지 도달한 어떤 앵커 MSE에서도 구도가 돌아오지 않았습니다. 앵커 MSE를 0.127까지 낮춘
첫 스텝도 구도를 앵커 target만큼 되돌리지 못했습니다. 첫 스텝에 DM 신호를 주자 렌더의
구도가 움직였고, 기타리스트 프롬프트는 모든 시드에서 점프하는 자세가 되었습니다. 렌더는 나아졌지만 다양성은
조금 줄었다고 평가했습니다.

### static 격자

| | 시드 간 유사도 | teacher 유사도 | 앵커 MSE |
|---|---|---|---|
| 동적 격자, seed 42 / 43 | 0.496 / 0.675 | 0.547 / 0.453 | 0.149 / 0.188 |
| static 격자 | **0.445** | **0.567** | 0.171 |

static 격자가 시드만 다른 동적 격자 두 런보다 다양성과 teacher 유사도에서 모두 나았고, 렌더 평가로 채택했습니다.
앵커 MSE는 두 동적 런 사이였고, 카페 간판 글자는 control보다 나빴습니다. static 격자는 한 시드만 돌렸습니다.

### cond-only CDM

CDM 항의 real score를 CFG를 건 teacher에서 cond teacher로 바꿨습니다. 다른 학습 곡선은 그대로였고, CDM 신호의
크기는 control의 0.71 → 0.53배로 줄었습니다.

| | teacher 유사도 | 앵커 MSE | 시드 간 유사도 |
|---|---|---|---|
| CFG를 건 CDM (control) | 0.547 | 0.151 | 0.451 |
| cond-only CDM | **0.608** | **0.138** | **0.442** |

세 프롬프트 모두에서 probe가 cond-only 쪽을 가리켰습니다. 렌더에서는 기타리스트가 teacher처럼 아래에서 올려다본
점프로 그려졌고(control은 서서 연주), 그룹 프롬프트의 카메라 구도가 다양해졌습니다. 대신 카페 앞치마 색이
teacher의 파란색에서 벗어났습니다. 한 시드, twin 없는 비교입니다.

## A4.3 배운 것의 측정

**측정 설정.** 2스텝 측정은 static 격자(σ 1 → 0.75 → 0)에서 했습니다. 이 격자에서 스텝 0은 앵커만, 스텝 1은 모든
DM을 받아서 두 스텝이 gradient를 나누지 않으므로, 그래프를 이어 스텝 0도 최종 이미지의 gradient를 받게
했습니다(rollout grad). 2스텝 기준 런은 LR 2e-5 constant에 GAN을 켠 런입니다. 4스텝의 기준 측정은 A4.2의 기준 설정
그대로 250 iteration, seed 42로 돌린 control과, seed만 43으로 바꾼 null twin입니다. 둘 다 125스텝마다 저장하고
validation 시드 8개로 probe를 돌렸습니다.

### A4.3.1 batch 1의 student는 random walk한다

**2스텝.** 저장된 체크포인트의 ΔW = up·down을 364개 모듈 전체에 대해 Frobenius norm으로 쟀습니다.

| 런 | LR, 스케줄 | \|ΔW\| @125 / 250 / 375 / 500 | 연속 125스텝 이동 사이 cos |
|---|---|---|---|
| 기준 런 (GAN) | 2e-5, constant | 2.77 / 3.98 / 4.85 / 5.50 | +0.018, −0.001 |
| GAN | 5e-5, constant | 6.54 / 9.74 / 12.37 / 14.77 | +0.012, +0.012 |
| GAN off, EMA 0.1 | 5e-5, constant | 6.66 / 9.27 / 11.23 / 12.77 | – |
| GAN off, CDM off, transition-aware fake | 5e-5, **cosine** | 5.71 / 7.74 / 8.21 / 8.26 | – |

- 상수 LR에서는 |ΔW|가 √t를 따릅니다(기준 런: 2.77·√(t/125) = 3.92 / 4.80 / 5.54). 125스텝 이동은 서로
  직교합니다. 되돌리는 힘도 한쪽으로 미는 힘도 없습니다.
- LR을 2.5배 낮추면 이동이 2.56배 줄어들 뿐 다른 것은 바뀌지 않습니다. Adam은 drift와 노이즈를 같은 비율로
  줄이므로 노이즈가 학습을 앞지르는 시점이 그대로입니다.
- walk는 GAN이 없어도 일어납니다. 멈춘 것은 cosine 런 하나(8.21 → 8.26)이고, 마지막 150스텝에 앵커 loss, DM 신호
  RMS, teacher와 fake velocity의 cos가 좋아진 것도 그 런뿐입니다.

**4스텝.**

| | control | twin |
|---|---|---|
| \|ΔW\| raw 125 / 250 | 7.34 / 10.33 | 7.49 / 10.54 |
| √2 · \|ΔW\|₁₂₅ | 10.37 | 10.59 |
| \|이동\| 0–125 / 125–250 | 7.34 / 7.14 | 7.49 / 7.21 |
| cos(이동 0–125, 이동 125–250) | 0.018 | 0.028 |
| \|ΔW\| EMA 250 | 8.73 | 8.98 |
| cos(EMA 250, raw 250) | 0.961 | 0.965 |

4스텝도 같은 상태입니다. 125스텝부터 √t로 자라고, 길이가 같고 서로 직교하는 두 번의 이동으로 이루어집니다.

**런 사이 공유분.** 두 런 ΔW 사이의 cos는 공유하는 에너지 비율로 읽을 수 있습니다.

| 쌍 | cos |
|---|---|
| 4스텝 control vs twin (시드만 다름), raw 125 / raw 250 / EMA 250 | 0.087 / 0.093 / 0.100 |
| 4스텝 500스텝 런 한 쌍 (시드·init·데이터 순서 같음, transition-aware fake만 다름) | 0.14 |
| 2스텝 기준 런 vs DM draw 4 런 (DM draw 수만 다름) @125 / 250 / 375 / 500 | 0.19 / 0.17 / 0.16 / 0.17 |
| 그 밖의 쌍 (LR이 다르거나 2스텝 vs 4스텝) @500 | 0.09–0.11 |

- 4스텝 student의 ΔW 중 약 85–90 %는 그 런에만 있는 성분입니다. 공유분은 특정 위치에 몰려 있지 않습니다. 모듈
  종류별로 0.11–0.19, 블록 그룹별로 0.10–0.21이고 마지막 블록 그룹(21–27)이 가장 높습니다.
- 시드만 바꿔도 0.09–0.10이 남습니다. 0.14였던 쌍은 데이터 순서까지 같았으므로, 그 0.14에는 데이터 순서의 몫이
  들어 있을 가능성이 큽니다.
- **ΔW overlap으로는 arm을 가를 수 없습니다.** 목적함수가 다른 arm도 reseed와 똑같이 읽힙니다.
- 시드 평균: 공유분이 c ≈ 0.14일 때 k개 시드의 exact ΔW 평균은 공유분을 $kc/(1+(k-1)c)$로 올립니다. k = 2면
  0.25, k = 4면 0.39입니다. 2스텝에서 두 런의 500 체크포인트를 평균한 것은 250 수준을 넘지 못했으므로, 시드
  평균은 품질을 올리지 못하고 정리 작업에 그칩니다.
- 런 한 쌍을 렌더로 비교한 A/B(예: A4.1의 transition-aware fake)는 이런 추첨 두 번을 비교한 것입니다.

### A4.3.2 스텝당 gradient는 대부분 노이즈다

2스텝 기준 런의 375스텝 체크포인트 하나에서 16샘플 × DM draw 3으로 gradient를 분해했습니다. 16샘플은 모두 가장
큰 토큰 버킷(4154–4200 토큰)에서 나왔습니다.

| student 스텝 방향 에너지 (clip 1.0이 남기는 단위 벡터 기준) | 비율 |
|---|---|
| 한 샘플 안의 (σ_a, ε_dm) draw 사이 | 77 % |
| 샘플 사이 | 20 % |
| 전체 평균 (누적되는 몫) | 3 % |

- 항별 제곱 norm 비율은 rollout 경로를 거친 DM 56 %, 스텝 1의 DM 13 %, 앵커 7 %, GAN 7 %입니다.
- DM gradient norm은 σ_a에 따라 커집니다. 중앙값이 0.25 미만에서 1.24, 이후 2.03, 2.36이고 0.75 초과에서
  4.93입니다. σ_a 0.96에서 21.9, 0.99에서 30.5가 나왔습니다. clip 아래에서는 이런 스텝도 다른 스텝과 같은 무게로
  들어갑니다.
- 평균 방향을 보면 DM과 앵커는 일치합니다(cos +0.55). GAN의 평균은 DM과 약간 반대입니다(−0.19).

### A4.3.3 노이즈를 줄여도 수준은 오르지 않는다

2스텝에서 노이즈를 줄이는 세 경로를 시험했는데, 모두 기준 런 250스텝 수준에서 멈췄습니다.

| 경로 | 런 | 결과 |
|---|---|---|
| DM draw 4 | 9.5 s/step (기준 런 6.5) | 실패. 250은 기준 런과 비슷하고 375는 자기 250보다 나쁘며 500은 회복. "좋아졌다 나빠졌다 다시 좋아지는" 것은 walk의 모습입니다. \|ΔW\| 2.80 / 3.92 / 4.70 / 5.35, 평균 몫 2.9 % (기준 런 3.0 %) |
| 체크포인트 exact 평균 | 기준 런의 250 / 375 / 500, 기준 런과 DM draw 4 런의 500, 두 런의 250 / 375 / 500(6개) | 500에서 생긴 벤치, 차량, 갈색 머리를 걷어 내지만, 어느 것도 기준 런 250을 넘지 못함 |
| gradient 누적 4 | 1000 it = 250 update, 72분, 4.0 s/it, 피크 13.79 GB | 실패. raw 최종은 둘 다보다 나쁘고(뒤틀린 몸), EMA 최종은 체크포인트 6개 평균 수준. \|ΔW\| 2.78 / 3.84, 이동 cos 0.022 |

- 4 draw가 4배 효과를 내지 못하는 이유는 σ_a tail입니다. 큰 draw는 대부분 노이즈이고, norm 가중으로 본 DM 평균
  몫은 1.6 %, 단위 가중으로는 4.3 %입니다. 4 draw 중 유효 draw 수는 2.23(iid 가정)입니다.
- **해석: 수준은 목적함수가 정하고, batch-1 walk는 거기서 빼기만 합니다.**

### A4.3.4 EMA는 walk 제거 장치다

- 2스텝에서 window 0.1(약 50스텝)의 EMA는 walk를 걷어 내지 못했습니다(기준 런 500: EMA |ΔW| 5.12, raw 5.50).
  window 0.2(gradient 누적 런)는 체크포인트 평균과 같은 수준까지 갔습니다.
- 4스텝 control에서 EMA 0.2는 raw 방향의 96 %를 유지하고 ΔW 길이를 15 % 줄입니다. 125스텝 이동 하나 안의 walk는
  지우지 못합니다.
- 2스텝에서 cosine LR은 walk를 멈춘 유일한 설정이었지만, LR은 walk가 시작되는 시점을 옮기지 않습니다. 지금
  레시피는 첫 스텝의 앵커 MSE 때문에 cosine을 쓰고(A4.2), 그 위에 LR 합 기준 EMA를 둡니다. 배포하는 것은 EMA
  체크포인트입니다.

### A4.3.5 발산 burst: raw 체크포인트가 그 안에 걸릴 수 있다

4스텝 control의 raw 250은 평가 렌더 12장(프롬프트 3개 × 시드 4개) 모두에서 평평한 노이즈 텍스처를 냈습니다.
파일은 정상이었고(같은 키, 유한값), 런이 마지막 몇 스텝에서 발산했습니다.

- student grad norm이 242–245스텝에서 5.5 / 14 / 6 / 16이다가 246–249에서 **231 / 244 / 106 / 72**가 되었습니다.
  fake grad norm도 같이 올라(25 → 111 / 69 / 145 / 85), student와 fake가 함께 터졌습니다.
- 그 구간의 σ_a는 0.03–0.96이므로 σ_a tail 탓이 아닙니다.
- x0 예측의 std가 0.74에서 1.98로 올랐고, 250 validation에서 FM MSE가 0.29 → 0.88, 최종 latent AC 유사도(A4.5)가
  0.948 → 0.999로 바뀌었습니다. A4.3.7의 붕괴 서명과 같습니다.
- twin도 153–162스텝에서 같은 종류의 burst(37 / 29 / 58 / **242** / 131)를 겪었지만 회복했습니다.
- EMA 0.2는 burst를 희석해서, control의 EMA 250은 정상으로 렌더됩니다. raw 125 + 250 평균에는 burst가 일부
  남습니다(기타리스트 프롬프트의 블록 같은 군중).

**상수 LR에서는 250 iteration에 한 번꼴로 burst가 났고, raw 체크포인트 하나가 그 안에 걸릴 수 있습니다. 그래서
raw를 배포하거나 raw끼리 비교하지 않습니다.**

### A4.3.6 grad clip 1.0은 정규화기다

clip 이전 student norm(5스텝 구간 평균)은 2스텝 런 네 개 모두에서 **모든 구간이 1.0을 넘었습니다**(중앙값
3.20–5.00, p95 7.4–10.1). fake도 마찬가지입니다(중앙값 2.2–2.9).

- Adam은 gradient의 상수배를 무시하므로 clip을 올려도 스텝이 커지지 않습니다. 스텝 크기는 LR이 정합니다. clip이
  정하는 것은 스텝끼리의 상대 무게입니다. 1.0이면 모든 스텝이 단위 norm으로 들어가고, clip이 없으면 norm만큼의
  무게로 들어갑니다.
- 2스텝에서는 큰 norm이 곧 노이즈였습니다. norm 가중을 하면 DM 평균 몫이 4.3 %에서 1.6 %로 떨어집니다.

**4스텝 σ_a 프로필** (clip 이전 student grad norm의 σ_a 사분위별 중앙값):

| | 0–0.25 | 0.25–0.5 | 0.5–0.75 | 0.75–1 | top/bottom | 중앙값 | p95 | max |
|---|---|---|---|---|---|---|---|---|
| control | 2.67 | 2.50 | 2.34 | 4.41 | 1.65 | 2.86 | 18.6 | 244 |
| twin | 2.80 | 2.54 | 3.05 | 3.57 | 1.27 | 2.91 | 12.9 | 242 |
| 합산 | 2.76 | 2.52 | 2.62 | 3.94 | **1.43** | 2.88 | 15.0 | 244 |

- 1.0 아래인 iteration이 하나도 없으므로 4스텝에서도 clip은 매 스텝 작동합니다.
- σ_a < 0.75에서는 평탄하고 맨 위 사분위에서만 오릅니다. 상승폭은 2스텝(4.9 / 1.2)보다 완만한데, rollout 경로가
  없다는 점과 맞습니다.

### A4.3.7 앵커 없는 루프는 붕괴한다

스텝 0에도 DM을 주고 다양성 가중을 0으로 두면(MFD 논문의 앵커 없는 루프) 250스텝 안에 student가 붕괴합니다.
스텝 0의 출력이 시드와 프롬프트에 상관없이 한 색이 되고, 4스텝 렌더는 인물 없는 노이즈 텍스처가 됩니다. 공통
설정은 soup teacher(int8), weight-SVD r64 / α180, transition-aware fake, 4스텝 + 동적 격자, DM 슬롯에 MFD(τ 간격
0.1, 최대 4스텝), GAN과 CDM off, lr 5e-5, 4:1, batch 1입니다.

| 런 | fake warmup | 최종 latent AC 유사도 @250 | 블록 AC 유사도 @250 | FM MSE @250 |
|---|---|---|---|---|
| 앵커 on (참조) | 200 | 0.940 | 0.678 | 0.357 |
| 앵커 off | 200 | 0.9994 | 0.077 | 0.371 |
| 앵커 off (250에서 중단) | 0 | 0.9996 | 0.155 | 0.452 |

- **학습 스칼라로는 보이지 않습니다.** 붕괴한 런의 DM 차의 상대 크기, teacher와 fake velocity의 cos, DM 차 RMS,
  grad norm은 참조 런 범위 안에 있습니다. 모든 velocity를 ε가 지배하기 때문입니다. 서명은 validation probe에
  나타납니다(A4.5).
- 원인에서 제외된 것은 g = 0 경로, transition-aware fake, fake LR warmup입니다. LoRA 자체도 원인이 아닙니다(MFD
  논문의 SANA 런도 student와 fake 모두 LoRA r64).
- 함정: 앵커를 없애도 DM 스칼라는 건강해 보입니다. 앵커는 다양성 장치이면서, 이 루프에서는 student를 붙잡아 두는
  힘이기도 합니다. 2스텝 측정에서 앵커와 DM의 평균 방향은 일치했습니다(A4.3.2).

### A4.3.8 MFD를 DM 슬롯에 넣기

MFD(Zhao et al. 2026, arXiv:2606.11155)는 점 하나의 차 $\tau(v_{real} - v_{fake})$ 대신, σ_a에서 σ_b까지 K번의
Euler로 teacher와 fake를 각각 적분한 끝점의 차를 씁니다. σ_b = 0, K = 1이면 DMD와 같습니다. 2스텝, base teacher와
공식 turbo delta init(A4.6), GAN off, 100 iteration 결과는 다음과 같습니다.

| arm | CDM | τ 간격 | 평균 K | s/step | DM 차 RMS 평균 ± sd |
|---|---|---|---|---|---|
| DMD | 1.0 | – | 1 | 5.33 | 0.194 ± 0.057 |
| MFD | 1.0 | 0.1 | 3.4 | 6.32 | 0.167 ± 0.041 |
| MFD | 0 | 0.03 | 17.2 | 11.30 | 0.185 ± 0.035 |

- DM 신호의 스텝 간 sd는 K 1 → 3.4에서 약 35 % 줄고, K 17에서는 더 줄지 않았습니다.
- 학습한 모든 arm에 init에는 없던 잡내용(하늘의 검은 형체, 두 번째 캔)이 생겼고, **K가 클수록 그 형체가 또렷한
  사물이 되었습니다**(K 17에서 악마 꼬리). 분산 감소로도, teacher ODE를 더 정확히 적분한 편향으로도 설명됩니다.
- CDM을 켜면 하늘이 하늘로 남았습니다. 500스텝 τ 간격 0.03, CDM off에서는 떠다니는 캔과 탑이 사라졌지만 꼬리와
  얼룩은 남았습니다.
- 레시피는 MFD를 쓰지 않습니다. 이 비교는 2스텝 100 iteration이고, MFD 논문의 T2I 결과는 4스텝 SANA
  3000스텝입니다.

## A4.4 효과가 없었던 시도

**2스텝 rollout grad.** A4.3의 2스텝 측정이 이 설정입니다. LR 5e-5와 2e-5 모두 250 체크포인트가 가장 좋았고, DM
draw 여러 번, gradient 누적, 체크포인트 평균도 이 수준을 넘지 못했습니다. LR 5e-5 런에서는 ~350스텝부터 disc가
폭주했습니다(margin 0.9–1.6, x0 예측 std → 0.43). **함정:** "250이 제일 좋다"는 walk의 모습이었습니다. raw
체크포인트 하나를 다른 하나와 비교하면 walk를 읽게 됩니다.

**APEX: student, reference, fake를 LoRA 하나로** (Liu et al. 2026, arXiv:2604.12322). 조건 이동 $c_{fake} = -c$로
LoRA 하나가 생성기와 fake를 겸하게 했습니다. step 시간은 3–5배 짧았습니다(1.3–2.1 s/it 대 6.7–7.0). 처음 제안한
변형($F - d$)은 55스텝부터 x0 예측 std가 0.77 → 7.6으로 폭주했고, 논문 형태(1500스텝)는 안정적이었지만 모든
체크포인트가 자기 warm start보다 흐리고 어두웠습니다. 감독 loss $\mathcal{L}_{sup}$이 student를 velocity field로
다시 끌어당기는데, velocity field를 4스텝 Euler로 풀면 조건부 평균이 나오기 때문으로 봅니다. **함정:** 논문 형태
런의 학습 스칼라(x0 예측 std 0.62, 롤아웃 std 포함)는 그리드가 망가지는 동안 내내 건강했습니다. 롤아웃 std는
폭주만 잡고 흐림은 못 잡습니다. 그래서 첫 체크포인트에서 그리드를 렌더합니다.

**DMAD: disc가 DM을 대신** (Yu et al. 2026, arXiv:2610.02188). fake critic을 classifier(teacher 대 student, real
대 student의 head 두 개)로 바꿨습니다. 같은 x0 예측에서 독립 DM 추정 두 개는 cos ≈ 0.12로만 일치합니다. 신호는
DP-DMD보다 2–18배 작았고, step은 11.9 s 대 6.6 s로, 논문은 4–5배 빠르다고 했지만 약 1.8배 느렸습니다. 결과는 "덜
움직였다"였습니다. raw 신호에 CDM을 더한 런(λ 150, 1500스텝)에서는 ~300–980스텝 동안 disc가 포화되어 입력
gradient가 사라졌고, x0 예측 std가 0.6 → 5로 올라 500 / 750 렌더가 줄무늬 텍스처로 붕괴했다가 1k에서 스스로
회복했습니다. **함정:** raw 신호는 상한이 없어 과하게 튀고, 포화된 disc는 student를 붙잡는 힘이 없습니다. 둘 다
λ로는 막을 수 없습니다.

**주파수 대역 결손에 맞춘 CFG 재가중.** student가 teacher보다 뒤처진 주파수 대역에 맞춰 CFG uplift를 재가중하는
방법입니다. 첫 probe는 student 롤아웃 상태(과도한 blur → 고주파 가중)를 쟀는데, loss는 실제 데이터를 다시 노이즈
입힌 점에서 재고 있었습니다(→ 저주파 가중). 즉 부호가 반대였습니다. on-trajectory에서 σ를 맞춰 다시 재니
student가 teacher보다 저주파를 더 가진(과도하게 흐린) 샘플이 3 %였습니다. 고칠 blur 결손이 없었고, DP-DMD 앵커가
이미 흡수한 것으로 봅니다. **함정:** go/no-go probe는 loss가 볼 바로 그 분포에서 같은 지표를 재야 합니다.

**GAN ↔ DM gradient surgery** (OPD²; Heo et al. 2026, arXiv:2607.15161). GAN gradient 중 DM과 부호가 어긋나는
성분만 막는 게이트를 검토했습니다. agree-energy가 0.489 ± 0.032로 permutation null 0.488 ± 0.011과 구별되지
않았고, GAN gradient와 DM 신호의 cos는 0.006이었습니다. GAN은 DM과 직교 방향으로 밀며, 원소당 크기는 DM의 약
6배(tail이 두꺼움)입니다. **함정 두 개:** 원소 부호 일치율 0.5는 직교의 기준선이고 충돌을 뜻하지 않습니다.
그리고 DM 서로게이트가 평균으로 줄여지므로 실제 적용되는 DM 힘은 DM 신호를 원소 수로 나눈 값이고, 원본 텐서끼리
비교하면 GAN을 ~10⁵배 과소평가합니다.

**τ 대역별 critic.** fake를 τ 대역별로 나누면 대역 간 간섭이 줄어드는지 봤습니다. 학습 끝의 annealed
LR(4.04e-6)에서는 신호가 17–19배로 통과 기준을 넘었지만, 실제 학습 peak LR(3e-5)에서는 기준을 넘지 못했습니다.
낮은 τ 대역만 학습한 clone이 높은 τ 대역도 개선했습니다. **함정:** probe fine-tune은 실제 학습 LR에서 돌려야
합니다. 작은 LR은 init 근처의 선형 영역만 재고, 노이즈 바닥을 낮춰서 SNR을 부풀립니다.

## A4.5 평가 세부

### 모멘트 갭

mode가 붕괴한 공식 turbo delta(A4.6)를 base teacher와 비교했습니다. 128 item, teacher 마지막
블록의 pooled feature로 쟀습니다. teacher CFG 1(T1)과 T4 사이의 nW2²는 0.186 / 0.189(τ 0.8 / 0.5)로 null의 약
17배이고, S–T4는 0.032 / 0.060입니다. S의 pooled spread는 T4 대비 0.885(τ 0.8), 0.858(τ 0.5), 0.798(latent 채널
평균)로 student의 분산이 부족합니다. 데이터셋은 CFG 1보다 CFG 4에 더 가깝습니다.

판단할 수 없습니다. 폭주는 bin 중앙값 spread > 0.40, disc margin > 0.5, disc loss < ~1.1(건강하면 1.33–1.36)이

## A4.6 base teacher

base DiT를 그대로 teacher로 쓰고, student와 fake는 기존 few-step 모델(공식 turbo 릴리스)에서
base에 대한 delta를 rank 96으로 뽑아(adaLN 포함) warm start했습니다. activation-aware SVD(ASVD; Yuan et al. 2023,
arXiv:2312.05821) 추출은 같은 rank의 plain SVD보다 재구성이 좋아서, rank 96 ASVD가 plain rank 128과 비슷합니다.
공식 turbo는 작동하는 few-step 맵이지만 mode가 붕괴해 있는데, DP-DMD 앵커가 mode를 다시 펼칩니다. warm start된
student는 0스텝부터 이미 few-step 맵이므로 증류는 fine-tune에 가깝습니다. 이 설정에서 본 것은 다음과 같습니다.
